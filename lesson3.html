核心觀念與選取器 (Core & Selectors)

CSS 的三種套用方式

實務上強烈建議使用外部樣式表 (External)，以達到「結構與樣式分離」的最佳實踐，利於維護。

<!-- 1. 行內 (Inline) - 盡量避免 -->
<p style="color: red;">Text</p>

<!-- 2. 內部 (Internal) - 寫在 head 內 -->
<style> p { color: blue; } </style>

<!-- 3. 外部 (External) - 業界標準 🌟 -->
<link rel="stylesheet" href="style.css">

CSS 選取器與權重

除了基本的標籤、Class (.) 與 ID (#) 外，掌握偽類 (Pseudo-classes) 能讓介面互動更豐富。

/* 群組與後代選取器 */
.navbar li a { color: #333; }

/* 屬性選取器 */
input[type="text"] { border: 1px solid #ccc; }

/* 偽類選取器 (滑鼠懸浮、子元素) */
.btn:hover { background-color: #0056b3; }
.list-item:nth-child(even) { background: #f9f9f9; }

現代排版利器 (Modern Layouts)

盒模型 (Box Model) 與陷阱

💡 box-sizing
預設的 content-box 會讓 padding 撐大元素總寬度。現代前端一律在全域設定 border-box，讓寬高包含 padding 與 border，排版才不會跑掉！ 
/* 現代前端起手式 (CSS Reset 概念) */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box; /* 🌟 關鍵屬性 */
}

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    /* 總寬度依然會是 200px 乖乖聽話 */
}

CSS3 Flexbox 彈性排版

取代傳統 float 的現代排版神器，能輕鬆解決垂直置中與等比例分配的問題。

.container {
    display: flex;
    /* 主軸對齊：分散對齊 */
    justify-content: space-between; 
    /* 交叉軸對齊：垂直置中 */
    align-items: center; 
    /* 允許子元素換行 */
    flex-wrap: wrap; 
    /* 元素間的間距 (CSS3 新特性) */
    gap: 20px; 
}

元素定位 (Positioning)

控制元素脫離正常文件流的方式。常搭配 z-index 調整層級。

.parent {
    position: relative; /* 建立定位基準 */
}
.child {
    position: absolute; /* 絕對定位 */
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%); /* 完美置中公式 */
}
/* 其他：fixed (固定視窗), sticky (滾動吸頂) */

CSS 變數與響應式 (RWD)

使用 :root 宣告變數方便統一管理主題色。並透過 Media Queries 讓網站適應手機與平板尺寸。

/* 宣告 CSS 變數 */
:root {
    --primary-color: #4A90E2;
}
.title { color: var(--primary-color); }

/* RWD 響應式設計：小於 768px 時觸發 */
@media screen and (max-width: 768px) {
    .container {
        flex-direction: column; /* 手機版改為直向排列 */
    }
}
