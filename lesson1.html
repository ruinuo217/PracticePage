Module 01: 網頁運作基礎與開發環境

Understanding Web Architecture & Environment Setup

核心概念 (Core Concepts)

Foundation

前端技術鐵三角

網頁的呈現由三大核心技術構成，它們在瀏覽器端（Client-side）共同協作：

  • HTML (骨架)： 負責建立網頁的內容結構與語意。
  • CSS (皮囊)： 控制網頁的視覺樣式、色彩與排版佈局。
  • JavaScript (肌肉)： 處理使用者的互動行為與動態資料渲染。

後端與伺服器架構

除了前端介面，一個完整的動態網站需要後端（Server-side）的支援：

  • PHP (伺服端語言)： 負責接收前端請求、處理商業邏輯，並產出動態內容回傳給瀏覽器。跨平台且廣泛應用。
  • MySQL (關聯式資料庫)： 用於整理與儲存網站資料（如會員資訊、文章）。穩定且開源，是 LAMP 架構的核心。

開發環境建置 (IDE)

建立高效的開發環境是第一步。目前業界最主流的前端編輯器：

  • Visual Studio Code (VS Code)： 微軟開發的免費、開源編輯器。
  • 推薦擴充套件 (Extensions)： Live Server (即時預覽)、Prettier (程式碼排版)、Auto Rename Tag。
