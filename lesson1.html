Module 01: 網頁運作基礎與開發環境

Understanding Web Architecture & Environment Setup

核心概念

1. 網頁是如何運作的？(Client-Server Model)

在開始寫程式之前，必須先理解當使用者在瀏覽器輸入網址時，背後發生了什麼事。這是所有網頁工程師的必備常識！

⚫ 用戶端 (Client-side)

通常指的是使用者的「瀏覽器」(如 Chrome、Safari)。它的主要工作是：

  • 發送 HTTP 請求 (Request) 給伺服器。
  • 接收伺服器傳回來的檔案 (HTML、CSS、JS、圖片)。
  • 將這些原始碼「渲染 (Render)」成我們肉眼看到的漂亮網頁。

⚫ 伺服器端 (Server-side)

一台24小時不關機、存放著你網站檔案的超級電腦。它的主要工作是：

  • 接收瀏覽器的請求，並進行邏輯判斷。
  • 如果需要，會去 資料庫 (Database) 撈取資料。
  • 將最終的結果打包成 回應 (Response) 傳回給用戶端。

2. 前端技術鐵三角 (The Front-End Trinity)

瀏覽器唯一看得懂的三種語言。現代前端開發就是建構在這三者的完美協作之上。

⚫ 職責分工與經典比喻

  • HTML (骨架)： 負責建立網頁的內容結構與語意 (如：哪裡是標題、哪裡是圖片)。
  • CSS (皮囊/化妝)： 控制網頁的視覺樣式、色彩、排版與動畫。
  • JavaScript (肌肉/神經)： 處理使用者的互動行為 (點擊按鈕、跳出視窗) 與動態資料抓取。

⚫ 程式碼是如何關聯的？

實務上，我們會將這三者寫在不同的檔案中，並透過 HTML 將它們串聯起來：

<!-- index.html 檔案 -->
<head>
    <!-- 引入 CSS 樣式表 -->
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>哈囉世界</h1>

    <!-- 引入 JavaScript 檔案 (通常放在 body 底部) -->
    <script src="script.js"></script>
</body>

3. 後端與資料庫架構 (Back-End & Database)

如果前端是餐廳的「外場」，那後端就是「廚房」。一個有會員登入、購物車功能的網站，絕對需要後端的支援。

💡 什麼是 LAMP 架構？
這是網頁開發史上最經典的後端技術組合：Linux (作業系統) + Apache (網站伺服器軟體) + MySQL (資料庫) + PHP (後端語言)。這也是你在後續課程即將掌握的強大武器！

⚫ PHP (後端伺服端語言)

負責接收前端傳來的表單（如帳號密碼），進行邏輯運算與身分驗證，並動態生成 HTML 回傳給瀏覽器。最大優勢是跨平台且伺服器支援度極高。

⚫ MySQL (關聯式資料庫)

負責將網站的數據（會員個資、商品清單、訂單紀錄）分門別類地儲存在資料表中。透過 SQL 語法，PHP 可以精準地對資料進行「新增、讀取、更新、刪除 (CRUD)」。

💡 現代開發環境建置 (Modern Dev Environment)

工欲善其事，必先利其器。打造一個舒服且高效的開發環境是工程師的第一課。

⚫ 前端利器：VS Code

微軟開發的免費開源編輯器，是目前業界絕對的主流。推薦安裝以下必備擴充套件 (Extensions)：

  • Live Server： 存檔即時更新瀏覽器畫面，切版必備。
  • Prettier： 程式碼自動排版神器，保持程式碼整潔。
  • Auto Rename Tag： 修改 HTML 標籤開頭時，結尾會自動跟著改。

⚫ 後端利器：本地端伺服器 (Localhost)

注意：PHP 檔案不能像 HTML 一樣直接點兩下在瀏覽器打開！它必須經過伺服器解析。
