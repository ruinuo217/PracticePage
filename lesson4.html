變數與基礎邏輯 (Variables & Logic)

變數宣告與資料型別

💡 Modern JS 觀念：
現代前端已棄用 var。請一律使用 let（宣告可變更的變數）與 const（宣告不可變更的常數），以避免區域變數污染的問題。 
// 現代變數宣告方式
let age = 25;      // 數字 (Number)
const name = "Reyna"; // 字串 (String) - 宣告後不可修改
let isDeveloper = true; // 布林值 (Boolean)

// typeof 運算子：用來檢查資料型別
console.log(typeof age); // 回傳 "number"

運算子與條件判斷

除了基本的 + - * / % 算數運算子，邏輯判斷在實務上極為重要。強烈建議使用 ===（全等）取代 ==。

let time = new Date().getHours();
let greeting = "";

// If...else if...else 判斷式
if (time < 12) {
    greeting = "Good morning";
} else if (time < 18) {
    greeting = "Good afternoon";
} else {
    greeting = "Good evening";
}

迴圈控制 (Loops)

用來重複執行代碼。常見有 for (已知次數)、while (未知次數，依條件執行)。

// 基礎 For 迴圈
for (let i = 0; i < 5; i++) {
    if (i === 3) break; // 跳出整個迴圈
    console.log("當前數字：" + i);
}

// 搭配陣列使用
const cars = ["BMW", "Volvo", "Ford"];
for (let i = 0; i < cars.length; i++) {
    console.log(cars[i]);
}

資料結構與函數 (Data & Functions)

函數 (Functions)

函數是可重複使用的代碼區塊，可以帶入參數 (Parameters) 並回傳值 (Return)。

// 帶有參數與回傳值的函數
function calculateArea(width, height) {
    let area = width * height;
    return area; // 將計算結果回傳
}

// 呼叫函數並將結果存入變數
const myArea = calculateArea(10, 5); 
console.log(myArea); // 輸出 50

陣列 (Array) & 物件 (Object)

陣列用來儲存有序清單；物件用來儲存具備「屬性」與「方法」的實體資料。

// 陣列 (Array) 與常用方法
const skills = ["HTML", "CSS", "JS"];
skills.push("React"); // 在結尾新增元素
console.log(skills.length); // 取得陣列長度

// 物件 (Object) 定義
const person = {
    firstName: "Reyna",
    role: "Frontend Developer",
    // 物件內的方法
    greet: function() {
        return "Hi, I am " + this.firstName;
    }
};
console.log(person.role); // 存取物件屬性

DOM 操作與事件聆聽

JavaScript 核心應用：操作網頁上的 HTML 元素並產生互動。

<!-- HTML 元素 -->
<p id="demo">原始文字</p>
<button id="myBtn">點擊更改</button>

<script>
// 1. 選取 DOM 元素
const demoText = document.getElementById("demo");
const btn = document.getElementById("myBtn");

// 2. 註冊點擊事件 (現代寫法)
btn.addEventListener("click", function() {
    demoText.innerHTML = "<strong>JavaScript 成功修改了內容！</strong>";
    demoText.style.color = "blue"; // 動態修改 CSS
});
</script>
