認識 DOM 與選取器 (DOM & Selectors)

文件物件模型 (DOM Tree)

當瀏覽器載入網頁時，會將 HTML 轉換成一個「樹狀結構 (Tree)」。這讓 JavaScript 獲得了改變網頁內容、屬性與 CSS 樣式的強大能力。

💡 核心概念： 網頁上的每一個標籤、屬性，甚至文字，在 DOM 裡都被視為一個「節點 (Node)」。

現代 DOM 選取器

業界主流已全面改用 querySelector，它允許我們像寫 CSS 一樣精準選取元素，取代了早期繁瑣的寫法。

// 傳統寫法 (較少用)
const el = document.getElementById("intro");
const items = document.getElementsByClassName("box");

// 🌟 現代寫法：querySelector (選取第一個)
const header = document.querySelector("#header");
const firstBox = document.querySelector(".box");

// 🌟 現代寫法：querySelectorAll (選取全部，回傳節點列表)
const allButtons = document.querySelectorAll("button");

操作內容與樣式 (Manipulation)

改變 HTML 內容與屬性

利用 JS 抓到元素後，可以直接動態修改文字、HTML 結構，甚至替換圖片來源。

const title = document.querySelector(".title");
const myImage = document.querySelector("#hero-img");

// 改變純文字 (比較安全，防 XSS 攻擊)
title.textContent = "New Header Title";

// 改變 HTML 結構 (可渲染標籤)
title.innerHTML = "<span>New Header</span>";

// 改變元素屬性 (例如替換圖片 src)
myImage.src = "new-landscape.jpg";
myImage.alt = "新的風景圖";

動態操作 CSS 樣式

可以直接修改 style，但實務上更推薦透過 classList 來切換預先寫好的 CSS 類別，好維護且乾淨。

const box = document.querySelector(".box");

// 方法 1：直接修改行內樣式 (Inline Style)
box.style.color = "blue";
box.style.backgroundColor = "red"; // 注意：要用駝峰命名法

// 方法 2：現代推薦做法 (切換 Class)
box.classList.add("active");    // 新增 class
box.classList.remove("hide");   // 移除 class
box.classList.toggle("dark");   // 切換 class (有則刪，無則加)

事件監聽與節點控制 (Events & Nodes)

事件監聽器 (addEventListener)

💡 不要再把 onclick 寫在 HTML 裡！使用 addEventListener 可以綁定多個事件，且讓結構與行為徹底分離。 
const btn = document.querySelector("#submit-btn");

// 常見事件：click, mouseover, mouseout, input, submit
btn.addEventListener("click", function(event) {
    // 阻止表單預設的重整行為 (極重要！)
    event.preventDefault(); 
    
    alert("按鈕被點擊了！");
});

動態建立新 HTML 元素

這是在做「待辦事項 (To-Do List)」或「無盡滾動文章」時絕對會用到的技巧。

// 1. 創建一個新的 <p> 元素
const newPara = document.createElement("p");

// 2. 為它加入文字內容與樣式
newPara.textContent = "這是由 JavaScript 動態產生的新段落。";
newPara.classList.add("text-highlight");

// 3. 找到要放入的父元素，並將新節點「附加」進去
const container = document.querySelector("#div1");
container.appendChild(newPara);
