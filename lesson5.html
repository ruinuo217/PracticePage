認識 DOM 與選取器 (DOM & Selectors)

文件物件模型 (DOM Tree)

當瀏覽器載入網頁時，會將 HTML 轉換成一個「樹狀結構 (Tree)」。這讓 JavaScript 獲得了改變網頁內容、屬性與 CSS 樣式的強大能力。

💡 核心概念： 網頁上的每一個標籤、屬性，甚至文字，在 DOM 裡都被視為一個「節點 (Node)」。

現代 DOM 選取器

業界主流已全面改用 querySelector，它允許我們像寫 CSS 一樣精準選取元素，取代了早期繁瑣的寫法。

// 傳統寫法 (較少用)
const el = document.getElementById("intro");
const items = document.getElementsByClassName("box");

// 🌟 現代寫法：querySelector (選取第一個)
const header = document.querySelector("#header");
const firstBox = document.querySelector(".box");

// 🌟 現代寫法：querySelectorAll (選取全部，回傳節點列表)
const allButtons = document.querySelectorAll("button");

操作內容與樣式 (Manipulation)

查找 HTML 元素 (Finding Elements)

要操作網頁，首先必須在 DOM 樹中「找到」目標元素。以下整理了傳統與現代的選取方法對比：

⚫ 傳統查找方式

過去常透過特定的 ID、標籤名稱或 Class 名稱來單獨尋找元素。

// 1. 通過 id 找到 HTML 元素 (回傳單一物件)
const intro = document.getElementById("intro");

// 2. 通過 tagname (標籤名) 找到 HTML 元素 (回傳集合)
const divs = document.getElementsByTagName("div");
// 也能在特定元素內繼續尋找
const paras = intro.getElementsByTagName("p");

// 3. 通過 class 找到 HTML 元素 (回傳集合)
const examples = document.getElementsByClassName("example");

⚫ 現代寫法：querySelector (推薦)

現代開發強烈建議統一使用 CSS 選擇器語法，更加直覺，且方便組合條件尋找。

// 1. 通過 id 尋找 (前方加上 #)
const introModern = document.querySelector("#intro");

// 2. 通過 tagname 尋找「所有」符合的標籤
const allDivs = document.querySelectorAll("div");

// 3. 通過 class 尋找「所有」符合的元素 (前方加上 .)
const allExamples = document.querySelectorAll(".example");

// 💡 強大優勢：可以直接使用複合型 CSS 選擇器！
// 例如：尋找 id 為 intro 裡面的所有 p 標籤
const introParas = document.querySelectorAll("#intro p");

改變 HTML 內容與屬性 (Content & Attributes)

HTML DOM 允許 JavaScript 動態改變 HTML 元素的內容與各種屬性。

💡 Modern JS 觀念：
1. 嚴禁濫用 document.write()：如果在網頁載入完成後才呼叫它，它會將整個 HTML 頁面覆蓋掉（包含你的腳本與樣式）。
2. 防範 XSS 攻擊：若只是要修改「純文字」，現代強烈推薦使用 textContent；只有在明確需要解析 HTML 標籤時，才使用 innerHTML。

⚫ 改變 HTML 輸出流與內容

// ⚠️ 傳統危險寫法：改變 HTML 輸出流
// document.write(Date()); // 載入後執行會覆蓋整個網頁

// 🌟 現代寫法：改變 HTML 內容
const header = document.querySelector("#header");

// 方法 A：只改變純文字 (推薦，安全且效能好)
header.textContent = "New Header Text";

// 方法 B：改變結構，會解析 HTML 標籤
header.innerHTML = "<span style='color:red'>New Header</span>";

⚫ 改變 HTML 屬性 (Attributes)

可以透過「點 . 語法」直接修改，或是使用 setAttribute() 方法。

const myImage = document.querySelector("#image");
const myLink = document.querySelector(".custom-link");

// 方法 A：直接透過屬性修改
myImage.src = "landscape.jpg";
myImage.alt = "優美的風景圖";
myLink.href = "https://google.com";

// 方法 B：使用 setAttribute (適合處理自訂的 data-* 屬性)
myImage.setAttribute("src", "landscape.jpg");
myImage.setAttribute("data-status", "loaded");

動態操作 CSS 樣式 (CSS Styles)

HTML DOM 允許 JavaScript 改變 HTML 元素的行內樣式，或是透過事件動態切換外觀。

💡 Modern JS 觀念：
1. 樣式屬性命名：在 CSS 中的 background-color，在 JS 中必須改用駝峰式命名 backgroundColor。
2. 職責分離：盡量避免在 HTML 中寫 onclick 屬性。現代作法是使用 addEventListener 監聽點擊，並且優先使用 classList.toggle 來切換預先寫好的 CSS，而非直接修改行內 style。

⚫ 改變 HTML 行內樣式 (Inline Style)

直接存取 DOM 的 style 物件，適合用在需要動態計算數值（例如隨鼠標移動的 X/Y 座標）的情境。

const p2 = document.querySelector("#p2");

// 修改文字顏色與字體大小
p2.style.color = "blue";
p2.style.fontSize = "24px";

// 修改背景顏色 (駝峰命名)
p2.style.backgroundColor = "#f4f4f4";

// 隱藏元素
p2.style.display = "none";

⚫ 透過事件動態改變樣式

將傳統寫法分離，改用現代的事件監聽與 classList。

<!-- ⚠️ 傳統寫法：HTML 綁定點擊事件 -->
<button onclick="document.getElementById('id1').style.color='red'">
    傳統點擊變色
</button>

<!-- 🌟 現代寫法：HTML 只負責結構 -->
<button id="colorBtn">現代點擊變色</button>

<script>
const colorBtn = document.querySelector("#colorBtn");
const targetText = document.querySelector("#id1");

// JS 負責行為：監聽點擊事件
colorBtn.addEventListener("click", () => {
    // 推薦：透過 classList 切換 CSS 寫好的 .text-red 類別
    targetText.classList.toggle("text-red");
});
</script>

事件監聽與節點控制 (Events & Nodes)

DOM 事件與監聽器 (Events & addEventListener)

我們可以在特定「事件」發生時執行 JavaScript，例如使用者點擊、輸入或滑鼠移動。

💡 Modern JS 觀念：
1. 行為與結構分離：不要再把 onclick="doSomething()" 寫在 HTML 標籤裡！現代強烈推薦使用 addEventListener 來綁定事件，這能對同一個元素綁定多個事件，且程式碼更好維護。
2. 捨棄 on 前綴：使用 addEventListener 時，事件名稱不需要加上 on 前綴（例如 onclick 要改寫成單純的 click）。

⚫ 常見 HTML 事件對照表

傳統 HTML 屬性現代 JS 監聽名稱觸發時機
onclickclick當用戶完成點擊時
onmousedownmousedown當用戶按下鼠標按鍵時
onmouseupmouseup當用戶放開鼠標按鍵時
onmouseovermouseover當鼠標移動到元素上方時
onmouseoutmouseout當鼠標移出元素時
onchangechange / input當輸入欄位內容改變時
onsubmitsubmit當提交 HTML 表單時
onloadload當圖片或整個頁面加載完成時

⚫ 現代事件監聽實作

透過 event (或縮寫為 e) 參數，我們可以取得觸發事件的詳細資訊（如輸入的值、滑鼠座標等）。

const btn = document.querySelector("#myBtn");
const form = document.querySelector("#myForm");
const inputField = document.querySelector("#myInput");

// 1. 滑鼠事件：滑鼠移入時改變背景色
btn.addEventListener("mouseover", () => {
    btn.style.backgroundColor = "yellow";
});

// 2. 表單事件：阻止預設送出並執行自訂邏輯
form.addEventListener("submit", (e) => {
    e.preventDefault(); // 🛑 極重要：阻止表單重整網頁
    console.log("表單已攔截，可在此執行 AJAX/Fetch 傳送資料！");
});

// 3. 輸入事件：即時取得輸入框的值
// 註：現代常用 input 事件取代 change，因為 input 是每打一個字就觸發
inputField.addEventListener("input", (e) => {
    console.log("目前輸入內容：", e.target.value);
});

動態建立與插入 HTML 元素 (Create & Append Nodes)

如需向 HTML DOM 添加新元素，必須先「創建」該元素節點，然後將它「插入」到頁面上已存在的元素中。這是在做「待辦事項 (To-Do List)」或「無盡滾動文章」時的必備技巧。

💡 Modern JS 觀念：
1. 捨棄 createTextNode：現代開發直接使用 textContent 賦值，語法更簡潔直覺。
2. 使用 append() 取代 appendChild()：append() 支援一次插入多個節點或純文字，且語法更具彈性。
3. 複雜結構推薦 insertAdjacentHTML：如果新元素包含大量巢狀標籤，使用樣板字面值搭配 insertAdjacentHTML 會比你一行一行寫 createElement 輕鬆非常多！

⚫ 節點建立：傳統 vs 現代寫法

// ⚠️ 傳統寫法：繁瑣的文字節點
const paraOld = document.createElement("p");
const nodeOld = document.createTextNode("這是舊寫法。");
paraOld.appendChild(nodeOld);
document.getElementById("div1").appendChild(paraOld);

// 🌟 現代寫法：直接操作屬性與 append
const newPara = document.createElement("p");
newPara.textContent = "由 JavaScript 動態產生的新段落。";
newPara.classList.add("text-highlight"); // 加入樣式

const container = document.querySelector("#div1");
container.append(newPara); // 現代推薦用 append

⚫ 靈活的插入位置與進階技巧

現代 JS 提供了更多方位的方法，以及處理複雜 HTML 結構的技巧。

const list = document.querySelector("#myList");
const newItem = document.createElement("li");
newItem.textContent = "新項目";

// 1. 多樣化的插入位置
list.append(newItem);  // 插入到容器的「最後面」
list.prepend(newItem); // 插入到容器的「最前面」
// 註：還有 newItem.before() 與 newItem.after() 可安插在特定元素前後

// 2. 🌟 複雜結構的終極殺手鐧：insertAdjacentHTML
// 不用再寫一堆 createElement，直接寫 HTML 結構字串！
const userName = "Reyna";
const cardHTML = `
    <div class="user-card">
        <h4>${userName}</h4>
        <p>Frontend Developer</p>
    </div>
`;
// 'beforeend' 效果等同 append，但會直接解析 HTML 字串
list.insertAdjacentHTML("beforeend", cardHTML);
