PHP 與 MySQL 連線 (Connection)

建立與關閉連線

MySQL 是與 PHP 搭配最流行的開源資料庫。在執行任何操作前，必須先透過 mysqli_connect 建立連線。

<?php
    $server = "localhost"; // 主機名稱
    $user = "root";        // 用戶名稱
    $pw = "password";      // 密碼
    $db = "my_database";   // 資料庫名稱

    // 1. 建立連線
    $conn = mysqli_connect($server, $user, $pw, $db);

    // 2. 檢查連線狀態
    if (!$conn) {
        die("連線失敗: " . mysqli_connect_error());
    } else {
        echo "連線成功！";
    }

    // 3. 關閉連線 (腳本結束通常會自動關閉，但手動關閉是好習慣)
    mysqli_close($conn);
?>

資料庫 CRUD 操作 (Create, Read, Update, Delete)

新增 (INSERT) 與資安觀念

🛡️ 資安面試必考：
實務上應避免直接將變數寫入 SQL 語法（易遭受 SQL 注入攻擊），建議使用 Prepared Statements。密碼也應使用 PHP 內建的 password_hash() 進行單向加密，而非舊版的 password()。 
<?php
    // 基礎新增語法
    $sql = "INSERT INTO member (mid, mpw, mname) 
            VALUES ('$mid', '$mpw', '$mname')";
            
    if (mysqli_query($conn, $sql)) {
        echo "資料新增成功";
    } else {
        echo "錯誤: " . mysqli_error($conn);
    }
?>

讀取 (SELECT)

使用 mysqli_fetch_assoc 將取得的資料轉換為關聯陣列，並搭配 while 迴圈逐筆印出。

<?php
    $sql = "SELECT mid, mname FROM member";
    $result = mysqli_query($conn, $sql);

    // 檢查是否有資料
    if (mysqli_num_rows($result) > 0) {
        // 逐筆抓取資料並轉換為關聯陣列
        while($row = mysqli_fetch_assoc($result)) {
            echo "ID : " . $row["mid"] . "<br>";
            echo "NAME : " . $row["mname"] . "<hr>";
        }
    } else {
        echo "沒有找到記錄";
    }
?>

更新 (UPDATE) 與 刪除 (DELETE)

執行完更新或刪除後，常搭配 header('location:...') 進行頁面重新導向。

<?php
    // --- 1. 更新記錄 ---
    $sql_update = "UPDATE member SET mname='$uname' WHERE mid='$uid'";
    
    if(mysqli_query($conn, $sql_update)) {
        header('location: select.php'); // 成功後導向列表頁
    } else {
        die('更新失敗');
    }

    // --- 2. 刪除記錄 ---
    $sql_delete = "DELETE FROM member WHERE mid='$uid'";
    
    if(mysqli_query($conn, $sql_delete)) {
        header('location: select.php');
    } else {
        die('刪除失敗');
    }
?>

狀態管理 (Cookies & Sessions)

Cookie (客戶端儲存)

Cookie 是伺服器留在用戶瀏覽器上的小檔案，適合儲存不敏感的偏好設定（如：記住帳號）。

<?php
    // 設定 Cookie (名稱, 值, 存活時間：目前時間+3600秒)
    setcookie("userName", "Reyna", time() + 3600);

    // 取得 Cookie
    if(isset($_COOKIE["userName"])) {
        echo "歡迎回來, " . $_COOKIE["userName"];
    }
?>

Session (伺服器端儲存)

Session 儲存在伺服器端，安全性較高，適合儲存敏感的臨時訊息（如：會員登入狀態）。使用者關閉瀏覽器即失效。

<?php
    // ⚠️ 必須在任何 HTML 輸出前呼叫！
    session_start(); 

    // 儲存 Session 訊息
    $_SESSION["isLogin"] = true;
    $_SESSION["role"] = "admin";

    // 取得 Session 訊息
    echo "目前的權限是: " . $_SESSION["role"];
    
    // 清除 Session (登出時使用)
    // session_destroy(); 
?>
