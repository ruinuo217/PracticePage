React 02: JSX 與 Component

學習 JSX 語法與元件化開發思維

JSX vs HTML 差異

JSX 看起來像 HTML，但其實是 JavaScript 的語法擴展。以下是兩者的關鍵差異：

項目 HTML JSX
CSS 類別 class="btn" className="btn"
行內樣式 style="color: red" style={{ color: 'red' }}
自閉合標籤 <img>、<br> <img />、<br />（必須加 /）
for 屬性 for="name" htmlFor="name"
註解 <!-- 註解 --> {/* 註解 */}
插入變數 不支援 {變數名稱}

用 {} 插入變數

在 JSX 中，使用大括號 {} 可以插入任何 JavaScript 表達式，包括變數、運算、函式呼叫等。

function App() { const name = 'Alice'; const age = 25; const scores = [90, 85, 92]; return ( <div> {/* 插入變數 */} <h2>使用者：{name}</h2> {/* 做運算 */} <p>明年 {age + 1} 歲</p> {/* 呼叫函式 */} <p>最高分：{Math.max(...scores)}</p> {/* 三元運算子 */} <p>{age >= 18 ? '成年' : '未成年'}</p> </div> ); }

JSX 注意事項

規則一：最外層只能有一個根元素
JSX 回傳的內容最外層只能有一個元素。如果不想多加一層 <div>， 可以使用空標籤 <>...</>（Fragment）來包裹。
// 錯誤：兩個根元素 return ( <h1>標題</h1> <p>內容</p> ) // 正確：用 Fragment 包起來 return ( <> <h1>標題</h1> <p>內容</p> </> )
規則二：return 多行要加小括號
如果 return 後面的 JSX 超過一行，必須用 () 包起來， 否則 JavaScript 會在 return 後面自動加上分號，導致什麼都不會回傳。

什麼是 Component？

Component（元件）是 React 的核心概念。把 UI 拆成獨立的積木，每個積木就是一個 Component。 就像樂高一樣，你可以用不同的積木組合出各種畫面。

元件化的好處：

  • 可重複使用：同一個元件可以在不同地方使用，不用重複寫程式碼
  • 容易維護：每個元件獨立管理自己的邏輯，修改一個不影響其他的
  • 容易協作：不同開發者可以分別負責不同元件
  • 容易測試：可以單獨測試每個元件的功能
命名規則：Component 名稱的首字母必須大寫！ 例如 StatCard、NavBar、UserProfile。 如果首字母小寫，React 會把它當成一般的 HTML 標籤。

建立第一個 Component

我們來建立一個簡單的 StatCard 元件，並在 App.jsx 中使用它：

步驟一：建立 src/components/StatCard.jsx

// src/components/StatCard.jsx function StatCard() { return ( <div className="card text-center shadow-sm" style={{ width: '18rem' }}> <div className="card-body"> <h5 className="card-title text-muted">總營收</h5> <p className="card-text fs-2 fw-bold">$12,500</p> </div> </div> ); } export default StatCard;

步驟二：在 App.jsx 中引入並使用

// src/App.jsx import StatCard from './components/StatCard'; function App() { return ( <div className="container mt-5"> <h1 className="mb-4">Dashboard</h1> <div className="d-flex gap-3"> <StatCard /> <StatCard /> <StatCard /> </div> </div> ); } export default App;

現在畫面上會出現 3 張一模一樣的卡片。但它們都顯示相同的內容， 要讓每張卡片顯示不同資料，就需要用到下一課的 Props！

建議的資料夾結構

隨著專案變大，建議按照以下方式組織檔案：

src/ ├── components/ # 可重複使用的元件 │ ├── StatCard.jsx │ ├── NavBar.jsx │ └── Footer.jsx ├── pages/ # 頁面元件（每個路由一個頁面） │ ├── Dashboard.jsx │ ├── Orders.jsx │ └── Settings.jsx ├── App.jsx # 根元件，組合所有頁面和元件 ├── main.jsx # 程式進入點，渲染 App └── custom.scss # 自訂樣式
  • components/：放可以在多個地方重複使用的元件（按鈕、卡片、導覽列等）
  • pages/：放頁面層級的元件，通常對應一個路由
  • App.jsx：負責組合所有頁面和佈局
  • main.jsx：程式的起點，把 App 渲染到 #root
