React 08: React Router 路由

實現多頁面切換，讓 SPA 擁有真正的頁面導覽

安裝與基礎設定

React 本身是 SPA（Single Page Application），只有一個 HTML 檔。 要實現「多頁面切換」的效果，需要安裝 React Router。 

npm install react-router-dom

在 main.jsx 用 BrowserRouter 包住整個 App：

// src/main.jsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import App from './App';
import './index.css';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
);

BrowserRouter 是路由的「容器」，它會監聽瀏覽器網址的變化， 然後根據設定的路由規則來決定顯示哪個元件。

定義路由：Routes + Route

在 App.jsx 中使用 Routes 和 Route 來定義每個頁面對應的路徑： 

// src/App.jsx
import { Routes, Route } from 'react-router-dom';
import Sidebar from './components/Sidebar';
import Dashboard from './pages/Dashboard';
import Orders from './pages/Orders';
import OrderDetail from './pages/OrderDetail';
import NotFound from './pages/NotFound';

function App() {
  return (
    <div className="app-layout">
      <Sidebar />
      <main className="main-content">
        <Routes>
          <Route path="/" element={<Dashboard />} />
          <Route path="/orders" element={<Orders />} />
          <Route path="/orders/:id" element={<OrderDetail />} />
          <Route path="*" element={<NotFound />} />
        </Routes>
      </main>
    </div>
  );
}
  • path="/"：首頁路徑，對應 Dashboard 元件
  • path="/orders"：訂單列表頁
  • path="/orders/:id"：動態路由，:id 是參數
  • path="*"：萬用路徑，所有不符合的路徑都顯示 404 頁面

Link 導覽 vs a 標籤

在 React Router 中，頁面切換要用 <Link> 而非 <a href>。 因為 <a> 會重新載入整個頁面，破壞 SPA 的優勢。 

import { Link, useLocation } from 'react-router-dom';

function Sidebar() {
  const location = useLocation();  // 取得目前路徑

  const menuItems = [
    { path: '/', label: '儀表板', icon: 'bi-speedometer2' },
    { path: '/orders', label: '訂單管理', icon: 'bi-receipt' },
    { path: '/products', label: '商品管理', icon: 'bi-box-seam' },
    { path: '/settings', label: '系統設定', icon: 'bi-gear' },
  ];

  return (
    <nav className="sidebar">
      {menuItems.map(item => (
        <Link
          key={item.path}
          to={item.path}
          className={`nav-item ${
            location.pathname === item.path ? 'active' : ''
          }`}
        >
          <i className={`bi ${item.icon}`} />
          {item.label}
        </Link>
      ))}
    </nav>
  );
}

重點：useLocation() 回傳目前的路徑資訊， 用 location.pathname 就能判斷現在在哪一頁，做出 active 高亮效果。

動態路由與 useParams

當頁面需要根據不同的 ID 顯示不同內容時，就要使用動態路由。 例如：/orders/123、/orders/456 都對應同一個元件。 

// 路由定義（App.jsx）
<Route path="/orders/:id" element={<OrderDetail />} />

// 元件中用 useParams 取得動態參數
import { useParams, useNavigate } from 'react-router-dom';

function OrderDetail() {
  const { id } = useParams();  // 取得網址中的 :id
  const navigate = useNavigate();  // 用來做程式化導航

  const [order, setOrder] = useState(null);

  useEffect(() => {
    fetch(`/api/orders/${id}`)
      .then(res => res.json())
      .then(data => setOrder(data));
  }, [id]);

  return (
    <div>
      <button onClick={() => navigate('/orders')}>
        返回訂單列表
      </button>
      <h2>訂單編號：{id}</h2>
      {order && (
        <div>
          <p>客戶：{order.customer}</p>
          <p>金額：${order.total}</p>
        </div>
      )}
    </div>
  );
}
  • useParams()：從網址中取得動態參數（:id → id）
  • useNavigate()：程式化導航，用在按鈕點擊或條件判斷後的頁面跳轉
  • useSearchParams()：取得查詢字串參數（?page=2&sort=name）

建議專案檔案結構

使用 React Router 後，專案結構建議按照「頁面」和「元件」來分資料夾： 

src/
├── main.jsx              # 入口，包 BrowserRouter
├── App.jsx               # 路由定義（Routes + Route）
├── index.css             # 全域樣式
│
├── pages/                # 頁面元件（對應路由）
│   ├── Dashboard.jsx     # 首頁儀表板    path="/"
│   ├── Orders.jsx        # 訂單列表      path="/orders"
│   ├── OrderDetail.jsx   # 訂單詳情      path="/orders/:id"
│   ├── Products.jsx      # 商品管理      path="/products"
│   ├── Settings.jsx      # 系統設定      path="/settings"
│   └── NotFound.jsx      # 404 頁面      path="*"
│
├── components/           # 共用元件（不對應路由）
│   ├── Sidebar.jsx       # 側邊欄導覽（放 Link）
│   ├── Header.jsx        # 頂部列
│   ├── StatCard.jsx      # 統計卡片
│   └── DataTable.jsx     # 資料表格
│
├── hooks/                # 自訂 Hook
│   ├── useFetch.js       # API 請求
│   └── useAuth.js        # 登入狀態
│
└── api/                  # API 相關
    └── client.js         # axios instance

命名慣例：

  • pages/ 資料夾：放「頁面級」的元件，每個檔案對應一條路由，用大寫開頭命名
  • components/ 資料夾：放可重複使用的 UI 元件，不直接對應路由
  • hooks/ 資料夾：放自訂 Hook，檔名以 use 開頭（例如 useFetch）
  • api/ 資料夾：放 API 相關設定，如 axios instance、API 路徑常數
