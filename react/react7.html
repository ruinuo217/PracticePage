React 07: API 串接實戰

用 fetch 與 axios 打 API，建立自訂 Hook 管理資料請求

fetch 基礎：三步驟取得資料

在 React 中串接 API 的標準流程：useEffect + fetch + setState。 同時要管理 loading 和 error 狀態，才能給使用者良好的體驗。 

import { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(res => {
        if (!res.ok) throw new Error('網路回應錯誤');
        return res.json();
      })
      .then(data => {
        setUsers(data);
        setLoading(false);
      })
      .catch(err => {
        setError(err.message);
        setLoading(false);
      });
  }, []);  // 空陣列 = 只執行一次

  if (loading) return <p>載入中...</p>;
  if (error) return <p>錯誤：{error}</p>;

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

三個必備的 state：data（資料）、loading（載入中）、error（錯誤訊息）， 這是 API 串接的標準模式。

async/await 改寫

.then() 鏈式寫法有時不好閱讀，可以改用 async/await。 但注意：useEffect 的回呼函式本身不能直接加 async，要在裡面另外宣告一個 async 函式。 

useEffect(() => {
  // 在 useEffect 裡面宣告 async 函式
  const fetchUsers = async () => {
    try {
      setLoading(true);
      const res = await fetch(
        'https://jsonplaceholder.typicode.com/users'
      );
      if (!res.ok) throw new Error('HTTP 錯誤');
      const data = await res.json();
      setUsers(data);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);  // 無論成功失敗都要關閉 loading
    }
  };

  fetchUsers();  // 呼叫剛才宣告的函式
}, []);

為什麼 useEffect 不能直接 async？
因為 useEffect 期望回傳值是 undefined 或 cleanup 函式。 而 async 函式會回傳 Promise，React 無法正確處理，所以要在裡面另外包一層。

為什麼用 axios？fetch vs axios 比較

axios 是更方便的 HTTP 請求工具，比原生 fetch 多了很多實用功能：

功能 fetch axios
JSON 解析 需手動 .json() 自動解析
HTTP 錯誤處理 404/500 不會 throw 自動 throw Error
baseURL 設定 不支援 支援
請求攔截器 不支援 支援（加 token 很方便）
取消請求 AbortController（較複雜） CancelToken（較簡單）

axios 實作：從安裝到使用

Step 1：安裝 axios

npm install axios

Step 2：建立 API Client（src/api/client.js）

// src/api/client.js
import axios from 'axios';

const apiClient = axios.create({
  baseURL: 'https://jsonplaceholder.typicode.com',
  timeout: 10000,  // 10 秒逾時
  headers: {
    'Content-Type': 'application/json',
  },
});

// 請求攔截器：自動加入 token
apiClient.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 回應攔截器：統一錯誤處理
apiClient.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // 未授權，導向登入頁
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

export default apiClient;

Step 3：在元件中使用 axios

import { useState, useEffect } from 'react';
import apiClient from '../api/client';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const res = await apiClient.get('/users');
        setUsers(res.data);  // axios 直接用 res.data 取資料
      } catch (err) {
        console.error('取得使用者失敗：', err.message);
      } finally {
        setLoading(false);
      }
    };
    fetchData();
  }, []);

  if (loading) return <p>載入中...</p>;
  return (
    <ul>
      {users.map(u => <li key={u.id}>{u.name} - {u.email}</li>)}
    </ul>
  );
}

自訂 Hook：useFetch

每個元件都要寫 loading、error、data 三個 state 太麻煩了！ 把這個邏輯封裝成自訂 Hook，一行就能搞定。 

// src/hooks/useFetch.js
import { useState, useEffect } from 'react';
import apiClient from '../api/client';

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    // 用 AbortController 來取消請求（避免元件卸載後還在 setState）
    const controller = new AbortController();

    const fetchData = async () => {
      try {
        setLoading(true);
        setError(null);
        const res = await apiClient.get(url, {
          signal: controller.signal,
        });
        setData(res.data);
      } catch (err) {
        if (err.name !== 'CanceledError') {
          setError(err.message);
        }
      } finally {
        setLoading(false);
      }
    };

    fetchData();

    // Cleanup：取消未完成的請求
    return () => controller.abort();
  }, [url]);  // url 改變時重新發請求

  return { data, loading, error };
}

export default useFetch;

使用方式 — 一行搞定 API 串接：

import useFetch from '../hooks/useFetch';

function UserList() {
  const { data: users, loading, error } = useFetch('/users');

  if (loading) return <p>載入中...</p>;
  if (error) return <p>錯誤：{error}</p>;

  return (
    <ul>
      {users.map(u => (
        <li key={u.id}>{u.name}</li>
      ))}
    </ul>
  );
}

// 也可以用在其他元件，超方便！
function PostList() {
  const { data: posts, loading } = useFetch('/posts');
  // ...
}

免費練習 API 推薦

以下是幾個適合練習的免費 API，不需要註冊就能使用：

  • JSONPlaceholder（jsonplaceholder.typicode.com）：提供假的 users、posts、comments 等資料，最適合入門練習
  • Open Meteo（open-meteo.com）：免費天氣 API，可以查詢全球各地的即時天氣與預報資料
  • REST Countries（restcountries.com）：提供全球國家資料，包含國旗、人口、首都等資訊
  • PokeAPI（pokeapi.co）：寶可夢資料 API，資料豐富，很適合做列表 + 詳細頁面練習
  • Fake Store API（fakestoreapi.com）：假的電商 API，有商品、購物車、使用者等，適合練習電商頁面
