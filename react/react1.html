React 01: 環境設定 Vite + React

使用 Vite 建立 React 開發環境，搭配 Bootstrap + Sass

什麼是 React？

React 是由 Facebook（現 Meta）開發並維護的 JavaScript UI 函式庫，專門用於建構使用者介面。 它不是完整的框架，而是專注在「View」這一層，讓開發者可以用「元件化」的方式來組裝畫面。

React 的三大核心概念：

  • Component-Based（元件化）：將 UI 拆成一個個獨立的積木，每個積木就是一個 Component，可以重複使用、獨立維護
  • Virtual DOM（虛擬 DOM）：React 不會直接操作真實 DOM，而是先在記憶體中建立虛擬 DOM，計算差異後再最小幅度地更新真實 DOM，效能更好
  • 單向資料流（One-Way Data Flow）：資料只能從父元件流向子元件，讓資料的流動更容易追蹤與除錯

Vite 專案建立

Vite 是新一代的前端建構工具，啟動速度極快（比 Create React App 快非常多）。 我們使用 Vite 來建立 React 專案：

建立全新專案：

# 建立名為 my-app 的 React 專案 npm create vite@latest my-app -- --template react # 進入專案資料夾 cd my-app # 安裝依賴套件 npm install

在現有資料夾中建立（不建立子資料夾）：

# 在當前目錄建立 React 專案（注意 . 代表當前目錄） npm create vite@latest . -- --template react

安裝 Bootstrap 與 Sass：

# 安裝 bootstrap 和 sass npm install bootstrap sass

專案結構說明

使用 Vite 建立的 React 專案，目錄結構如下：

my-app/ ├── node_modules/ # 所有安裝的套件（不需要手動修改，也不上傳 Git） ├── public/ # 靜態資源（圖片、favicon 等，不會被 Vite 處理） ├── src/ # 主要開發區域，所有程式碼都寫在這裡 │ ├── App.jsx # 根元件，整個應用的入口元件 │ ├── App.css # App 元件的樣式 │ ├── main.jsx # 程式的起點，負責把 App 渲染到 DOM │ └── index.css # 全域樣式 ├── index.html # 唯一的 HTML 檔案，只有一個 <div id="root"> ├── package.json # 專案設定、依賴套件清單、scripts 指令 ├── vite.config.js # Vite 的設定檔 └── .gitignore # Git 忽略清單（node_modules 等）
重點觀念：SPA（Single Page Application）
整個專案只有一個 index.html，裡面只有一個 <div id="root"></div>。 React 會把所有元件渲染到這個 div 裡面。切換頁面時不是載入新的 HTML，而是由 JavaScript 動態替換畫面內容。 這就是所謂的「單頁應用程式」。

Bootstrap + Sass 設定

我們可以透過 Sass 來自訂 Bootstrap 的主題色彩，讓專案有自己的風格。

步驟一：建立 src/custom.scss

// src/custom.scss // 1. 自訂 Bootstrap 變數（必須在 import 之前） $primary: #5a67d8; $success: #48bb78; $danger: #f56565; $warning: #ecc94b; $info: #4299e1; // 2. 引入 Bootstrap 的完整樣式 @import "bootstrap/scss/bootstrap";

步驟二：修改 src/main.jsx，引入 custom.scss

// src/main.jsx import React from 'react' import ReactDOM from 'react-dom/client' import App from './App.jsx' import './custom.scss' // 引入自訂的 Bootstrap 樣式 ReactDOM.createRoot(document.getElementById('root')).render( <React.StrictMode> <App /> </React.StrictMode>, )

啟動開發伺服器

一切準備好之後，啟動開發伺服器來預覽成果：

# 啟動 Vite 開發伺服器 npm run dev # 預設開啟網址：http://localhost:5173

清除預設內容，開始動手寫：

// src/App.jsx — 清除預設內容，寫上自己的第一行 function App() { return ( <div className="container mt-5"> <h1>Hello Dashboard!</h1> <p>我的 React 學習之旅開始了！</p> </div> ) } export default App
小提醒：Vite 的 HMR（Hot Module Replacement）功能非常快速， 修改程式碼後存檔，瀏覽器會立即反映變更，不需要手動重新整理頁面！
