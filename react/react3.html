React 03: Props 資料傳遞

透過 Props 讓 Component 接收不同資料，實現真正的重複使用

什麼是 Props？

Props（Properties 的縮寫）是從父元件傳給子元件的資料。 有了 Props，同一個 Component 就可以根據接收到的資料顯示不同的內容， 真正實現「一個元件，多種用途」。

你可以把 Props 想像成函式的參數：

// 一般函式：透過參數接收不同資料 function greet(name) { return `Hello, ${name}!`; } greet('Alice'); // "Hello, Alice!" greet('Bob'); // "Hello, Bob!" // React Component：透過 Props 接收不同資料 function StatCard({ title, value }) { return <div>{title}: {value}</div>; } <StatCard title="營收" value="$12,500" /> <StatCard title="訂單" value="356" />
重要觀念：Props 是唯讀的（Read-Only）， 子元件不能修改從父元件接收到的 Props。資料只能從父元件流向子元件，這就是「單向資料流」。

Props 基礎用法

父元件（傳送端）：像 HTML 屬性一樣傳入資料

// App.jsx（父元件） <StatCard title="總營收" value="$12,500" color="primary" /> <StatCard title="總訂單" value="356" color="success" /> <StatCard title="總客戶" value="1,280" color="info" />

子元件（接收端）：用解構賦值接收 Props

// StatCard.jsx（子元件） // 方法一：直接在參數用解構賦值（推薦） function StatCard({ title, value, color }) { return ( <div className={`card border-${color}`}> <h5>{title}</h5> <p className={`text-${color}`}>{value}</p> </div> ); } // 方法二：用 props 物件（較不常用） function StatCard(props) { return ( <div className={`card border-${props.color}`}> <h5>{props.title}</h5> <p>{props.value}</p> </div> ); }

StatCard 改造範例

讓我們把上一課的 StatCard 元件改造成可以接收 Props 的版本：

StatCard.jsx — 接收 title, value, color 三個 props

// src/components/StatCard.jsx function StatCard({ title, value, color }) { return ( <div className={`card border-${color} border-2 shadow-sm h-100`}> <div className="card-body text-center"> <h6 className="card-title text-muted text-uppercase"> {title} </h6> <p className={`card-text fs-2 fw-bold text-${color}`}> {value} </p> </div> </div> ); } export default StatCard;

App.jsx — 傳入不同資料，產生 3 張不同的卡片

// src/App.jsx import StatCard from './components/StatCard'; function App() { return ( <div className="container mt-5"> <h1 className="mb-4">Dashboard</h1> <div className="row g-3"> <div className="col-md-4"> <StatCard title="總營收" value="$12,500" color="primary" /> </div> <div className="col-md-4"> <StatCard title="總訂單" value="356" color="success" /> </div> <div className="col-md-4"> <StatCard title="總客戶" value="1,280" color="info" /> </div> </div> </div> ); } export default App;

現在同一個 StatCard 元件，只要傳入不同的 Props，就能顯示完全不同的內容和顏色。 這就是元件化 + Props 的威力！

Props 的特性

  • 唯讀（Read-Only）：子元件絕對不能修改收到的 Props。 如果需要可變的資料，要用 State（下一課會學到）
  • 單向資料流（父 → 子）：Props 只能從父元件傳給子元件， 子元件不能直接把資料傳回父元件
  • 可傳任何型別：字串、數字、布林值、陣列、物件、甚至函式都可以當作 Props 傳遞
// 傳遞不同型別的 Props <MyComponent name="Alice" {/* 字串 */} age={25} {/* 數字（用 {} 包裹） */} isAdmin={true} {/* 布林值 */} scores={[90, 85]} {/* 陣列 */} user={{ id: 1 }} {/* 物件 */} onClick={handleClick} {/* 函式 */} />

進階練習：加上趨勢指標

在 StatCard 加上 trend prop，顯示在卡片下方。 根據趨勢的正負值，自動變換顏色和圖示：

// StatCard.jsx — 加入 trend prop function StatCard({ title, value, color, trend }) { // 判斷趨勢方向 const isPositive = parseFloat(trend) > 0; return ( <div className={`card border-${color} border-2 shadow-sm h-100`}> <div className="card-body text-center"> <h6 className="text-muted text-uppercase">{title}</h6> <p className={`fs-2 fw-bold text-${color}`}>{value}</p> {/* 有 trend 才顯示 */} {trend && ( <small className={isPositive ? 'text-success' : 'text-danger'}> {isPositive ? '▲' : '▼'} {trend} </small> )} </div> </div> ); } // 使用方式 <StatCard title="營收" value="$12,500" color="primary" trend="+5.2%" /> <StatCard title="退貨" value="23" color="danger" trend="-2.1%" />

這裡用到了條件渲染 {trend && (...)}：只有當 trend 有值時才會顯示趨勢指標。 這是非常實用的 React 技巧，後面會深入學習。
