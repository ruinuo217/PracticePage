React 05: 列表與條件渲染

根據資料動態產生 UI，掌握 .map() 與條件判斷

三種條件渲染寫法

在 React 中，根據條件決定要顯示什麼內容，有三種常見的寫法：

寫法一：三元運算子（最常用）

// 條件 ? 成立時顯示 : 不成立時顯示 {isLoggedIn ? <UserPanel /> : <LoginButton />} // 實際範例 <span className={`badge bg-${order.status === '已出貨' ? 'success' : 'warning'}`}> {order.status} </span>

寫法二：&& 短路求值（只有成立才顯示）

// 條件成立才顯示，不成立就什麼都不渲染 {hasError && <p className="text-danger">發生錯誤！</p>} {unreadCount > 0 && <span className="badge bg-danger">{unreadCount}</span>}

寫法三：提前 return（整個元件不渲染）

function DataTable({ data, loading }) { // 載入中 → 提前回傳 loading 畫面 if (loading) return <p>載入中...</p>; // 沒有資料 → 提前回傳空狀態 if (data.length === 0) return <p>暫無資料</p>; // 正常渲染 return <table>...</table>; }

Tab 切換範例

結合 useState 和條件渲染，做出 Tab 頁籤切換的效果：

import { useState } from 'react'; function Dashboard() { const [activeTab, setActiveTab] = useState('overview'); return ( <div> {/* Tab 按鈕列 */} <ul className="nav nav-tabs mb-3"> <li className="nav-item"> <button className={`nav-link ${activeTab === 'overview' ? 'active' : ''}`} onClick={() => setActiveTab('overview')} > 總覽 </button> </li> <li className="nav-item"> <button className={`nav-link ${activeTab === 'orders' ? 'active' : ''}`} onClick={() => setActiveTab('orders')} > 訂單 </button> </li> <li className="nav-item"> <button className={`nav-link ${activeTab === 'users' ? 'active' : ''}`} onClick={() => setActiveTab('users')} > 用戶 </button> </li> </ul> {/* Tab 內容：用 && 條件渲染 */} {activeTab === 'overview' && <div>這是總覽頁面的內容</div>} {activeTab === 'orders' && <div>這是訂單列表</div>} {activeTab === 'users' && <div>這是用戶管理</div>} </div> ); }

點擊不同的 Tab 按鈕 → setActiveTab 更新 State → React 重新渲染 → 對應的 className 和內容同時更新。

用 .map() 渲染列表

在 React 中，要把陣列資料渲染成 UI，最常用的方法就是 .map()。 它會遍歷陣列中的每一筆資料，回傳對應的 JSX 元素。

import { useState } from 'react'; function OrderTable() { const [orders] = useState([ { id: 1, customer: '王小明', product: 'MacBook Pro', amount: 59900, status: '已出貨' }, { id: 2, customer: '李小華', product: 'iPhone 15', amount: 35900, status: '處理中' }, { id: 3, customer: '張大偉', product: 'AirPods Pro', amount: 7490, status: '已出貨' }, { id: 4, customer: '陳美美', product: 'iPad Air', amount: 22900, status: '已取消' }, { id: 5, customer: '林小安', product: 'Apple Watch', amount: 13900, status: '處理中' }, ]); return ( <table className="table table-hover"> <thead> <tr> <th>#</th> <th>客戶</th> <th>商品</th> <th>金額</th> <th>狀態</th> </tr> </thead> <tbody> {orders.map((order) => ( <tr key={order.id}> <td>{order.id}</td> <td>{order.customer}</td> <td>{order.product}</td> <td>${order.amount.toLocaleString()}</td> <td> <span className={`badge bg-${ order.status === '已出貨' ? 'success' : order.status === '處理中' ? 'warning' : 'danger' }`}> {order.status} </span> </td> </tr> ))} </tbody> </table> ); }
關鍵：每個元素都要有 key！
key={order.id} 是 React 用來追蹤每個元素的唯一識別碼。 有了 key，React 才能高效地判斷哪些元素需要更新、新增或刪除。 通常使用資料的 id 作為 key 值。

加上搜尋篩選

結合 .filter() 和 .map()，可以做出即時搜尋篩選的效果：

import { useState } from 'react'; function OrderTable() { const [keyword, setKeyword] = useState(''); const [orders] = useState([ { id: 1, customer: '王小明', product: 'MacBook Pro', amount: 59900 }, { id: 2, customer: '李小華', product: 'iPhone 15', amount: 35900 }, { id: 3, customer: '張大偉', product: 'AirPods Pro', amount: 7490 }, ]); // 先 filter 篩選，再 map 渲染 const filtered = orders.filter((o) => o.customer.includes(keyword) || o.product.includes(keyword) ); return ( <div> <input type="text" className="form-control mb-3" placeholder="搜尋客戶或商品..." value={keyword} onChange={(e) => setKeyword(e.target.value)} /> <p className="text-muted"> 搜尋結果：{filtered.length} 筆 </p> {filtered.length === 0 ? <p>沒有符合的資料</p> : filtered.map((order) => ( <div key={order.id} className="card mb-2 p-3"> <strong>{order.customer}</strong> - {order.product} （${order.amount.toLocaleString()}） </div> )) } </div> ); }

輸入關鍵字 → setKeyword 更新 State → React 重新渲染 → filtered 會根據新的 keyword 重新計算 → 畫面只顯示符合條件的項目。

重點提醒

關於 key 的重要規則：
  • .map() 渲染的每個元素都必須有 key prop，沒有會出現 console 警告
  • key 值必須在兄弟元素之間是唯一的（不需要全域唯一）
  • 最佳做法：使用資料本身的 id 作為 key
  • 不要用 index 當 key（除非列表是靜態的、不會重新排序或增刪）

為什麼不要用 index 當 key？

// 不好的做法 {orders.map((order, index) => ( <tr key={index}>...</tr> // 當列表增刪或重排時，會導致渲染錯誤 ))} // 好的做法 {orders.map((order) => ( <tr key={order.id}>...</tr> // 用唯一且穩定的 id ))}

當列表項目被新增、刪除或重新排序時，index 會跟著改變。 React 會誤認為元素沒有變動，導致畫面顯示錯誤或效能問題。 使用穩定且唯一的 id 才能讓 React 正確追蹤每個元素。

本課重點摘要：

  • 條件渲染：三元運算子、&& 短路求值、提前 return，三種方式依情境選用
  • 列表渲染：使用 .map() 將陣列轉換成 JSX 元素，記得加 key
  • 搜尋篩選：.filter() + .map() 組合技，搭配 useState 做即時搜尋
  • 資料驅動畫面：不需要手動操作 DOM，只需要更新資料，React 自動更新畫面
