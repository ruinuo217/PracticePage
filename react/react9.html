React 09: Context 與 UI 元件庫

用 Context API 管理全域狀態，搭配 Ant Design 打造專業介面

為什麼需要 Context？

在 React 中，資料透過 Props 從父元件一層一層往下傳。但如果元件層級很深， 中間的元件根本不需要這些資料，卻被迫要接收再往下傳 — 這就是「Props Drilling（Props 鑽孔）」問題。 

// Props Drilling 的痛苦
// App → Layout → Sidebar → UserInfo → Avatar
// user 資料要經過 4 層才能到 Avatar，中間 3 層都只是「轉傳」

<App user={user}>                    {/* 有 user */}
  <Layout user={user}>                {/* 只是轉傳 */}
    <Sidebar user={user}>             {/* 只是轉傳 */}
      <UserInfo user={user}>          {/* 只是轉傳 */}
        <Avatar src={user.avatar} />  {/* 真正用到的地方 */}
      </UserInfo>
    </Sidebar>
  </Layout>
</App>

Context 解決的問題：讓任何層級的元件都能「直接」取用資料，不需要一層一層傳。

  • 登入狀態：整個 App 都需要知道目前是否已登入、登入的使用者是誰
  • 語言切換（i18n）：所有元件都需要知道目前的語言設定
  • 深色模式（Dark Mode）：全域的主題顏色切換
  • 購物車資料：多個頁面都需要存取購物車內容

建立 Context：三步驟完整範例

以「登入狀態管理」為例，展示 Context 的三個步驟：createContext → Provider → useContext

Step 1：建立 AuthContext（src/contexts/AuthContext.jsx）

// src/contexts/AuthContext.jsx
import { createContext, useContext, useState } from 'react';

// 1. 建立 Context
const AuthContext = createContext(null);

// 2. 建立 Provider 元件（管理狀態 + 提供方法）
export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);

  // 登入
  const login = (userData) => {
    setUser(userData);
    localStorage.setItem('user', JSON.stringify(userData));
  };

  // 登出
  const logout = () => {
    setUser(null);
    localStorage.removeItem('user');
  };

  // 判斷是否已登入
  const isAuthenticated = !!user;

  // 把 state 和方法都透過 value 傳出去
  return (
    <AuthContext.Provider value={{ user, login, logout, isAuthenticated }}>
      {children}
    </AuthContext.Provider>
  );
}

// 3. 建立自訂 Hook（方便取用）
export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth 必須在 AuthProvider 內使用');
  }
  return context;
}

Step 2：在任何子元件中直接取用

// 在任何元件中直接使用 useAuth()
import { useAuth } from '../contexts/AuthContext';

function Header() {
  const { user, logout, isAuthenticated } = useAuth();

  return (
    <header>
      {isAuthenticated ? (
        <>
          <span>歡迎，{user.name}</span>
          <button onClick={logout}>登出</button>
        </>
      ) : (
        <Link to="/login">請登入</Link>
      )}
    </header>
  );
}

套用 Provider

在 main.jsx 最外層包上 Provider，這樣所有子元件都能存取 Context 中的資料： 

// src/main.jsx
import { AuthProvider } from './contexts/AuthContext';
import { BrowserRouter } from 'react-router-dom';

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <BrowserRouter>
      <AuthProvider>
        <App />
      </AuthProvider>
    </BrowserRouter>
  </StrictMode>
);

Provider 的包裹順序很重要：外層的 Provider 可以被內層的所有元件取用。 如果有多個 Provider（Auth、Theme、Cart），通常從外到內依序包裹。 

// 多個 Provider 巢狀
<BrowserRouter>
  <ThemeProvider>
    <AuthProvider>
      <CartProvider>
        <App />
      </CartProvider>
    </AuthProvider>
  </ThemeProvider>
</BrowserRouter>

Ant Design 安裝與設定

Ant Design（antd）是由螞蟻金服開發的企業級 UI 元件庫，提供豐富的高品質元件， 特別適合做後台管理系統。 

# 安裝 Ant Design
npm install antd

# 安裝圖示庫（選用）
npm install @ant-design/icons

在 main.jsx 引入樣式：

// src/main.jsx
import 'antd/dist/reset.css';  // antd 5.x 的重置樣式
import './index.css';           // 自己的樣式放在後面

antd 5.x 的特色：

  • 使用 CSS-in-JS，不再需要引入整包 CSS
  • 支援 Tree Shaking，只打包有用到的元件
  • 內建 ConfigProvider 可以全域設定主題色

常用 Ant Design 元件

1. Button 按鈕：

import { Button, Space } from 'antd';
import { SearchOutlined, DeleteOutlined } from '@ant-design/icons';

function ActionButtons() {
  return (
    <Space>
      <Button type="primary">主要按鈕</Button>
      <Button>預設按鈕</Button>
      <Button type="primary" danger>危險按鈕</Button>
      <Button type="primary" loading>載入中</Button>
      <Button icon={<SearchOutlined />}>搜尋</Button>
      <Button icon={<DeleteOutlined />} danger />
    </Space>
  );
}

2. Table 表格（最常用！）：

import { Table, Tag } from 'antd';

function OrderTable({ orders }) {
  const columns = [
    {
      title: '訂單編號',
      dataIndex: 'id',
      key: 'id',
    },
    {
      title: '客戶名稱',
      dataIndex: 'customer',
      key: 'customer',
    },
    {
      title: '金額',
      dataIndex: 'total',
      key: 'total',
      render: (value) => `NT$ ${value.toLocaleString()}`,  // 自訂顯示
    },
    {
      title: '狀態',
      dataIndex: 'status',
      key: 'status',
      render: (status) => {
        const colorMap = {
          '已完成': 'green',
          '處理中': 'blue',
          '已取消': 'red',
        };
        return <Tag color={colorMap[status]}>{status}</Tag>;
      },
    },
  ];

  return (
    <Table
      columns={columns}
      dataSource={orders}
      rowKey="id"
      pagination={{ pageSize: 10 }}
    />
  );
}

4. Form 表單驗證：

import { Form, Input, Button, message } from 'antd';

function LoginForm() {
  const onFinish = (values) => {
    console.log('表單資料：', values);
    message.success('登入成功！');
  };

  return (
    <Form layout="vertical" onFinish={onFinish}>
      <Form.Item label="帳號" name="username"
        rules={[{ required: true, message: '請輸入帳號' }]}>
        <Input placeholder="請輸入帳號" />
      </Form.Item>

      <Form.Item label="密碼" name="password"
        rules={[
          { required: true, message: '請輸入密碼' },
          { min: 6, message: '密碼至少 6 個字元' },
        ]}>
        <Input.Password placeholder="請輸入密碼" />
      </Form.Item>

      <Button type="primary" htmlType="submit" block>
        登入
      </Button>
    </Form>
  );
}
