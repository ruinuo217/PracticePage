React 04: useState 狀態管理

用 useState 讓畫面動起來，學習事件處理

什麼是 State？

State（狀態）是 Component 自己管理的資料。 跟 Props 不同，State 是元件內部的，可以被修改。

當 State 改變時，React 會自動重新渲染（re-render）該元件的畫面。 這就是 React 最核心的魔法：「資料驅動畫面」。

比較項目 Props State
資料來源 父元件傳入 元件自己管理
可否修改 不可修改（唯讀） 可以透過 set 函式修改
修改後效果 父元件重新渲染時子元件跟著更新 自動觸發元件重新渲染

useState 基礎用法

useState 是 React 提供的 Hook（鉤子），用來在函式元件中建立 State。

import { useState } from 'react'; function Counter() { // 解構賦值：[目前的值, 更新用的函式] = useState(初始值) const [count, setCount] = useState(0); return ( <div> <p>目前計數：{count}</p> <button onClick={() => setCount(count + 1)}>+1</button> </div> ); }
絕對禁止：直接修改 State 變數！
count = count + 1 是錯誤的做法。React 不會知道資料改了，畫面不會更新。 一定要透過 setCount() 這個 set 函式來更新 State。

計數器範例

一個完整的計數器，包含加、減、重置功能：

import { useState } from 'react'; function Counter() { const [count, setCount] = useState(0); return ( <div className="text-center p-4"> <h2 className="mb-3">計數器</h2> <p className="display-4 fw-bold">{count}</p> <div className="d-flex gap-2 justify-content-center"> <button className="btn btn-success" onClick={() => setCount(count + 1)} > + 1 </button> <button className="btn btn-danger" onClick={() => setCount(count - 1)} > - 1 </button> <button className="btn btn-secondary" onClick={() => setCount(0)} > 重置 </button> </div> </div> ); }

每次點擊按鈕，setCount 會更新 count 的值， React 偵測到 State 變化後，自動重新渲染畫面，顯示新的數字。

即時搜尋欄

用 useState 搭配 onChange 事件，可以做出即時搜尋的效果：

import { useState } from 'react'; function SearchBar() { const [keyword, setKeyword] = useState(''); return ( <div className="p-4"> <h2>即時搜尋</h2> <input type="text" className="form-control mb-3" placeholder="輸入關鍵字..." value={keyword} onChange={(e) => setKeyword(e.target.value)} /> <p>你輸入了：<strong>{keyword}</strong></p> <p>字數：{keyword.length}</p> </div> ); }

關鍵概念：受控元件（Controlled Component）
input 的 value 綁定 State 變數，onChange 更新 State。 這樣 React 完全掌控 input 的值，稱為「受控元件」。這是 React 表單處理的標準做法。

事件處理整理

React 常用的事件處理方式：

事件 說明 範例
onClick 點擊事件 onClick={() => setCount(count + 1)}
onChange 輸入變化事件 onChange={(e) => setKeyword(e.target.value)}
onSubmit 表單提交事件 onSubmit={(e) => { e.preventDefault(); ... }}
onMouseEnter 滑鼠移入 onMouseEnter={() => setHovered(true)}
onKeyDown 鍵盤按下 onKeyDown={(e) => e.key === 'Enter' && submit()}
常見錯誤：事件綁定的寫法
正確：onClick={() => handleClick()} 或 onClick={handleClick}
錯誤：onClick={handleClick()} — 這樣會在渲染時就立即執行函式，而不是等到點擊時才執行！
// 抽出事件處理函式（推薦做法） function App() { const [count, setCount] = useState(0); // 把邏輯抽出來，程式碼更清晰 const handleIncrement = () => setCount(count + 1); const handleDecrement = () => setCount(count - 1); const handleReset = () => setCount(0); return ( <div> <p>{count}</p> <button onClick={handleIncrement}>+1</button> <button onClick={handleDecrement}>-1</button> <button onClick={handleReset}>重置</button> </div> ); }
