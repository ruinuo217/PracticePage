Recharts 安裝與折線圖

Recharts 是基於 D3 的 React 圖表庫，用宣告式元件的方式畫圖表， 非常直覺好上手。 

npm install recharts

折線圖（LineChart）範例：

import {
  ResponsiveContainer, LineChart, Line,
  XAxis, YAxis, Tooltip, Legend, CartesianGrid
} from 'recharts';

const salesData = [
  { month: '1月', revenue: 45000, orders: 120 },
  { month: '2月', revenue: 52000, orders: 145 },
  { month: '3月', revenue: 48000, orders: 132 },
  { month: '4月', revenue: 61000, orders: 178 },
  { month: '5月', revenue: 55000, orders: 156 },
  { month: '6月', revenue: 67000, orders: 195 },
];

function SalesChart() {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <LineChart data={salesData}>
        <CartesianGrid strokeDasharray="3 3" />
        <XAxis dataKey="month" />
        <YAxis />
        <Tooltip />
        <Legend />
        <Line type="monotone" dataKey="revenue"
              stroke="#6366f1" name="營收" />
        <Line type="monotone" dataKey="orders"
              stroke="#f59e0b" name="訂單數" />
      </LineChart>
    </ResponsiveContainer>
  );
}
  • ResponsiveContainer：讓圖表自動適應父容器寬度
  • CartesianGrid：背景格線，strokeDasharray 設定虛線
  • Tooltip：滑鼠移到資料點時的彈出提示
  • Legend：圖例說明

長條圖與圓餅圖

長條圖（BarChart）：適合做數值比較

import { ResponsiveContainer, BarChart, Bar,
         XAxis, YAxis, Tooltip } from 'recharts';

function CategoryChart({ data }) {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <BarChart data={data}>
        <XAxis dataKey="category" />
        <YAxis />
        <Tooltip />
        <Bar dataKey="count" fill="#6366f1" radius={[4,4,0,0]} />
      </BarChart>
    </ResponsiveContainer>
  );
}

圓餅圖（PieChart）：適合顯示比例分佈

import { ResponsiveContainer, PieChart, Pie,
         Cell, Tooltip } from 'recharts';

const COLORS = ['#6366f1', '#f59e0b', '#10b981', '#ef4444'];

function StatusPie({ data }) {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <PieChart>
        <Pie data={data} dataKey="value" nameKey="name"
             cx="50%" cy="50%"
             innerRadius={60}  {/* innerRadius > 0 = 甜甜圈圖 */}
             outerRadius={100} label>
          {data.map((_, i) => (
            <Cell key={i} fill={COLORS[i % COLORS.length]} />
          ))}
        </Pie>
        <Tooltip />
      </PieChart>
    </ResponsiveContainer>
  );
}

.dashboard-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* 統計卡片：各佔 1/3 */
.stat-card {
  /* 自動排列在三欄中 */
}

/* 折線圖：佔滿整行 */
.chart-line {
  grid-column: 1 / -1;  /* 從第 1 欄到最後 */

/* 長條圖 + 圓餅圖：各佔一半 */
.chart-bar {
  grid-column: span 2;  /* 佔 2 欄 */

.chart-pie {
  grid-column: span 1;  /* 佔 1 欄 */
}

/* 訂單表格：佔滿整行 */

  grid-column: 1 / -1;
}

RWD 響應式設計

使用 CSS Grid 的 auto-fit + minmax 讓佈局自動適應不同螢幕寬度： 

/* 自動響應式：欄數根據螢幕寬度自動調整 */
.dashboard-grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(280px, 1fr));
  gap: 20px;
}

/* 手機版：隱藏側邊欄，用漢堡選單 */
@media (max-width: 768px) {
  .sidebar {
    position: fixed;
    left: -260px;  /* 預設隱藏 */
    transition: left 0.3s;
  }
  .sidebar.open {
    left: 0;
  }
  .hamburger-btn {
    display: block;  /* 手機版才顯示 */
  }
}

useWindowSize 自訂 Hook：

// src/hooks/useWindowSize.js
import { useState, useEffect } from 'react';

function useWindowSize() {
  const [size, setSize] = useState({
    width: window.innerWidth,
    height: window.innerHeight,
  });

  useEffect(() => {
    const handleResize = () => {
      setSize({
        width: window.innerWidth,
        height: window.innerHeight,
      });
    };
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);

  return size;
}

// 使用方式
function Dashboard() {
  const { width } = useWindowSize();
  const isMobile = width < 768;

  return isMobile
    ? <MobileDashboard />
    : <DesktopDashboard />;
}

Dark Mode 深色模式

用 CSS 變數管理顏色，搭配 [data-theme='dark'] 覆蓋變數值，實現深色模式切換： 

/* CSS 變數定義 */
:root {
  --bg-primary: #ffffff;
  --bg-secondary: #f8f9fa;
  --text-primary: #1a1a2e;
  --text-secondary: #6b7280;
  --border-color: #e5e7eb;
  --card-bg: #ffffff;
}

/* 深色模式覆蓋 */
[data-theme='dark'] {
  --bg-primary: #1a1a2e;
  --bg-secondary: #16213e;
  --text-primary: #e2e8f0;
  --text-secondary: #94a3b8;
  --border-color: #334155;
  --card-bg: #1e293b;
}

ThemeContext 全域管理 + localStorage 記住選擇：

// src/contexts/ThemeContext.jsx
import { createContext, useContext, useState, useEffect } from 'react';

const ThemeContext = createContext();

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState(
    () => localStorage.getItem('theme') || 'light'
  );

  useEffect(() => {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('theme', theme);
  }, [theme]);

  const toggleTheme = () => {
    setTheme(prev => prev === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);

// 切換按鈕元件
function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {theme === 'light' ? '🌙 深色模式' : '☀️ 淺色模式'}
    </button>
  );
}

部署到 Vercel

Vercel 是最適合前端專案的部署平台，支援 React / Vite 專案一鍵部署，且免費方案就很夠用。

Step 1：建置專案

# 先在本地測試建置是否成功
npm run build

# 建置完成後，產生 dist/ 資料夾
# 這就是要部署的靜態檔案

Step 2：部署方式（二選一）

# 方式一：Vercel CLI
npm install -g vercel
vercel          # 第一次部署，會引導你設定
vercel --prod   # 之後部署到正式環境

# 方式二：連接 GitHub（推薦）
# 1. 將專案推送到 GitHub
# 2. 到 vercel.com 登入 → Import Project
# 3. 選擇你的 GitHub Repo
# 4. Vercel 自動偵測 Vite，設定 Build Command 和 Output Directory
# 5. 每次 push 到 main 分支，自動部署！

Step 3：修正 React Router 的 404 問題

SPA 的路由是由前端 JavaScript 處理的，但 Vercel 伺服器不知道這些路由。 直接輸入 /orders/123 會出現 404。需要設定 rewrites： 

// vercel.json（放在專案根目錄）
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}

Step 4：環境變數設定

# .env.local（本地開發用，不要上傳到 Git）
VITE_API_URL=http://localhost:3000/api
VITE_APP_TITLE=My Dashboard

# 在程式碼中使用
const apiUrl = import.meta.env.VITE_API_URL;

# 在 Vercel 後台設定正式環境的環境變數
# Settings → Environment Variables → 加入 VITE_API_URL

注意：Vite 的環境變數必須以 VITE_ 開頭才會被打包進前端程式碼。 不以 VITE_ 開頭的變數不會暴露給瀏覽器，適合放伺服器端的密鑰。

效能優化技巧

1. useMemo 避免重複計算：

import { useMemo } from 'react';

function Dashboard({ orders }) {
  // 只在 orders 改變時才重新計算
  const totalRevenue = useMemo(() => {
    return orders.reduce((sum, o) => sum + o.total, 0);
  }, [orders]);

  const topProducts = useMemo(() => {
    return [...orders]
      .sort((a, b) => b.total - a.total)
      .slice(0, 5);
  }, [orders]);

  return <div>總營收：{totalRevenue}</div>;
}

2. 骨架屏 Skeleton Loading：

// 用 Ant Design 的 Skeleton 元件
import { Skeleton, Card } from 'antd';

function DashboardCard({ loading, title, value }) {
  return (
    <Card>

      ) : (

        </>

}

import { Empty } from 'antd';

function OrderList({ orders }) {
