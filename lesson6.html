jQuery 基礎語法與選取器

起手式與文檔就緒

為了確保 DOM 元素都已經完全載入，所有的 jQuery 代碼都應該包裝在 ready() 函數中。

// 基礎語法結構：$(selector).action()

// 確保文檔完全加載 (文檔就緒函數)
$(document).ready(function() {
    
    // 你的 jQuery 代碼寫在這裡
    console.log("jQuery is ready!");
    
});

強大的選擇器 (Selectors)

利用 $() 包裹 CSS 選擇器，就能輕鬆抓取網頁元素。

// 基本選擇器
$("p")        // 標籤選擇器
$(".intro")   // Class 選擇器
$("#demo")    // ID 選擇器

// 屬性選擇器
$("[href]")   // 帶有 href 屬性的元素
$("[href$='.jpg']") // href 值以 .jpg 結尾的元素

DOM 操作與事件綁定

內容、屬性與類別操作

jQuery 提供極簡的方法來取得 (Get) 或設定 (Set) 元素的內容與樣式。

// 內容操作
$("#text").text("Hello");       // 修改純文字
$("#box").html("<b>Hi</b>");  // 修改 HTML 結構
$("#input").val("Reyna");       // 修改表單輸入值

// 屬性與類別操作
$("img").attr("src", "new.jpg"); // 修改屬性
$("p").addClass("highlight");    // 新增 class
$("p").removeClass("highlight"); // 移除 class

事件監聽 (Events)

💡 jQuery 的強項： 原生 JS 的 querySelectorAll 抓到多個元素後必須使用迴圈才能綁定事件，但在 jQuery 裡，它會自動幫所有符合的元素綁定事件！ 
// 滑鼠點擊事件
$("button").click(function() {
    $("p").hide(); // 隱藏所有段落
});

// 使用 on() 綁定多個事件或未來動態產生的元素
$(document).on("click", "li", function() {
    $(this).remove(); // 點擊列表項目即刪除自己
});

動畫特效 (Effects & Animations)

基礎特效 (淡入淡出 / 滑動)

能快速製作 UI 互動效果。參數可填入速度 ("slow", "fast" 或毫秒)。

// 顯示與隱藏
$("#panel").toggle("fast");

// 淡入與淡出
$("#box").fadeToggle(1000); // 1秒內切換淡入/淡出
$("#box").fadeTo("slow", 0.5); // 透明度漸變至 50%

// 上下滑動 (常應用於手風琴選單)
$(".menu").slideDown();

自訂動畫與鍊式寫法 (Chaining)

使用 animate() 改變 CSS 屬性，並使用鍊式寫法將多個動作串接起來，依序執行。

// 自訂動畫 (屬性名需改用駝峰式)
$("div").animate({
    left: '250px',
    opacity: '0.5',
    width: '150px'
});

// 🌟 鍊式寫法 (Chaining)：一個元素執行多道指令
$("#p1").css("color", "red")
        .slideUp(2000)
        .slideDown(2000);
