jQuery 基礎語法與選取器

1. jQuery 基礎語法與起手式

💡 Modern jQuery 觀念：
傳統的 $(document).ready(function(){}) 在 jQuery 3.0 之後已被官方標記為不推薦 (Deprecated)！現代標準請一律改用簡寫版本 $(function() { ... })，若搭配 ES6 箭頭函數則寫為 $(() => { ... })。

⚫ 核心語法結構

基礎語法：$(selector).action()

  • $：定義/存取 jQuery 函式庫。
  • (selector)：尋找網頁中的 HTML 元素。
  • .action()：對元素執行的操作動作。
$(this).hide();     // 隱藏當前元素
$("p").hide();      // 隱藏所有段落
$(".test").hide();  // 隱藏所有 class="test" 的元素
$("#test").hide();  // 隱藏所有 id="test" 的元素

⚫ 文檔就緒函數 (Document Ready)

為了防止在 DOM 完全加載之前運行代碼（例如試圖隱藏不存在的元素，或獲取未加載的圖片大小），必須將代碼包裝在就緒函數中。

// ⚠️ 傳統寫法 (過於冗長，現代不推薦)
$(document).ready(function() {
    // 執行代碼...
});

// 🌟 現代 jQuery 推薦縮寫
$(function() {
    // 執行代碼...
});

// 🌟 現代 jQuery 搭配 ES6 箭頭函數
$(() => {
    console.log("DOM 已載入，jQuery 準備就緒！");
});

2. 強大的選擇器與樣式操作

jQuery 的選擇器語法完美支援 CSS 選擇器，這也是現代原生 JS querySelector 的靈感來源。

⚫ 元素與屬性選擇器

// 1. 元素與 Class/ID 選擇器
$("p")         // 選取 <p> 元素
$("p.intro")   // 選取 class="intro" 的 <p> 元素
$("p#demo")    // 選取 id="demo" 的 <p> 元素

// 2. 屬性選擇器
$("[href]")             // 選取帶有 href 屬性的元素
$("[href='#']")         // 選取 href 值等於 "#" 的元素
$("[href!='#']")        // 選取 href 值「不等於」"#" 的元素
$("[href$='.jpg']")     // 選取 href 值以 ".jpg"「結尾」的元素

⚫ 操作 CSS 樣式與鏈式寫法

使用 .css() 可以動態更改屬性。jQuery 的一大優勢是「鏈式寫法 (Chaining)」，可以一次串接多個動作。

// 更改單一 CSS 屬性
$("p").css("background-color", "red");

// 更改多個 CSS 屬性 (傳入物件格式)
$("p.intro").css({
    "background-color": "yellow",
    "font-size": "20px"
});

// 🌟 jQuery 特色：鏈式寫法 (Chaining)
// 選取後，先變更顏色、再滑動隱藏、再滑動顯示
$("#demo").css("color", "blue").slideUp(2000).slideDown(2000);

DOM 操作與事件綁定 (DOM & Events)

內容、屬性與樣式操作 (Content & Attributes)

💡 jQuery 核心觀念：Getter / Setter 同體
jQuery 非常聰明，同一個方法（如 text()、css()），不傳參數時是「取得 (Get)」，傳入參數時則是「設定 (Set)」。這讓程式碼看起來極度乾淨！

⚫ 取得與設定內容 (text, html, val)

對應原生 JS 的 textContent、innerHTML 與 value。

// --- 取得內容 (Get) ---
let myText = $("#test1").text();   // 返回純文字
let myHtml = $("#test1").html();   // 返回 HTML 結構
let myVal = $("#test2").val();     // 返回表單欄位的值

// --- 設定內容 (Set) ---
$("#test1").text("Hello");
$("#test2").html("<b>Hello world!</b>");
$("#test3").val("I am Dragon");

⚫ 取得與設定屬性、類別、樣式

// --- 操作屬性 (Attribute) ---
$("img").attr("src", "images/3.jpg"); // 設定 src 屬性
$("table").removeAttr("border");      // 移除 border 屬性

// --- 操作 Class 類別 ---
$("p").addClass("pre");       // 新增類別
$("p").removeClass("pre");    // 移除類別
$("p").toggleClass("pre");    // 切換類別

// --- 操作 CSS 樣式 ---
let bgColor = $("p").css("background-color"); // 取得背景色
$("p").css("background-color", "yellow");     // 設定單一樣式
$("p").css({ "color": "red", "font-size": "20px" }); // 設定多個樣式

動態添加與刪除元素 (Add & Remove Elements)

比起原生 JavaScript，jQuery 提供了更直覺的方位插入方法，以及更方便的刪除機制。

⚫ 添加新內容的四個方位

  • append()：在被選元素的結尾 (內部) 插入。
  • prepend()：在被選元素的開頭 (內部) 插入。
  • after()：在被選元素之後 (外部) 插入。
  • before()：在被選元素之前 (外部) 插入。
let element = "<span> 新節點 </span>";

$("ol").append("<li>" + element + "</li>");
$("ol").prepend("<li>" + element + "</li>");
$("#box").after(element);
$("#box").before(element);

⚫ 刪除元素或內容

remove() 會連根拔起，而 empty() 只會清空肚子裡的內容。

// 刪除被選元素 (包含它自己與所有子元素)
$("#div1").remove();

// 從被選元素中刪除所有子元素 (它自己還留著，但變空了)
$("#div1").empty();

事件綁定與尺寸計算 (Events & Dimensions)

💡 jQuery 事件綁定的強項：自動遍歷
在原生 JS 中，抓到多個按鈕必須用迴圈才能一一綁定事件；而在 jQuery 裡，$("button").click() 會自動幫所有找到的按鈕都綁上事件，這是 jQuery 極度好用的設計！

⚫ 常見事件與動態事件委派 on()

包含：click, dblclick, focus, mouseover, mouseout 等。

// 一般事件綁定
$("button").click(function() {
    $("p").hide(); // 點擊按鈕隱藏所有的 <p>
});

// 🌟 進階技巧：動態事件委派 (Event Delegation)
// 使用 on() 綁定在父元素(如 document)上，
// 這樣「未來」才動態產生的 <li> 也會有點擊事件！
$(document).on("click", "li", function() {
    // 點擊誰，誰就刪除自己
    $(this).remove(); 
});

⚫ 尺寸計算方法 (Dimensions)

jQuery 提供了快速計算元素各種寬高的方法，這在做捲動特效或版面計算時非常重要。

  • width() / height()：僅計算內容寬高。
  • innerWidth() / innerHeight()：內容寬高 + Padding 內距。
  • outerWidth() / outerHeight()：內容寬高 + Padding 內距 + Border 邊框。
let boxW = $("#div1").width();
let boxInnerW = $("#div1").innerWidth();
let boxOuterW = $("#div1").outerWidth();

console.log(`寬度: ${boxW}, 含內距: ${boxInnerW}, 含邊界: ${boxOuterW}`);

動畫特效 (Effects & Animations)

內建基礎特效 (Show/Hide, Fade, Slide)

💡 參數規則：
大多數特效的語法為 $(selector).effect(speed, callback)。
speed：動畫速度，可填寫毫秒 (如 1000 為 1 秒) 或是 "slow"、"fast"。
callback：動畫 100% 完成後才會執行的函數。

⚫ 顯示 / 隱藏與淡入 / 淡出

// 1. 顯示與隱藏 (切換顯示狀態)
$("p").hide(1000);   // 隱藏
$("p").show("fast"); // 顯示
$("p").toggle();     // 在 hide() 和 show() 之間切換

// 2. 淡入與淡出 (控制透明度至 0 或 100%)
$("#div1").fadeIn("slow");
$("#div2").fadeOut(3000);
$("#div3").fadeToggle(); // 切換淡入與淡出

// 3. 淡化至特定透明度 (0 ~ 1 之間)
$("#div4").fadeTo("fast", 0.5); // 淡化到 50% 透明度

⚫ 上下滑動 (Slide)

透過改變元素高度來產生滑動效果，非常適合用於「手風琴選單」或「下拉式面板」。

// 點擊按鈕，讓面板向下滑動顯示
$("#flipDown").click(function() {
    $("#panel").slideDown("slow");
});

// 點擊按鈕，讓面板向上滑動隱藏
$("#flipUp").click(function() {
    $("#panel").slideUp("fast");
});

// 點擊按鈕，自動判斷狀態切換滑動方向
$("#flipToggle").click(function() {
    $("#panel").slideToggle(1000);
});

自訂動畫與列隊 (Animate & Queue)

語法：$(selector).animate({params}, speed, callback)

💡 CSS 屬性寫法提醒：
使用 animate() 時，CSS 屬性必須使用 Camel 標記法 (駝峰式)，例如 padding-left 必須寫成 paddingLeft。
注意：元素預設為靜態位置 (static) 無法移動，若要操作 left、top，必須先在 CSS 將 position 設為 relative、fixed 或 absolute！

⚫ 自訂動畫與預定義值

// 操作多個屬性
$("div").animate({
    left: '250px',
    opacity: '0.5',
    width: '150px',
    height: '150px'
});

// 使用預定義的值 ("show", "hide", "toggle")
$("div").animate({
    width: 'toggle',
    height: 'toggle'
});

⚫ 動畫列隊功能 (Queue)

如果針對同一個元素寫了多個動畫，jQuery 會自動把它們放入佇列中，一項一項依序執行。

$("button").click(function() {
    let div = $("div");
    
    // 以下動畫會依序執行：
    // 1. 先向右移動 100px
    div.animate({left: '100px'}, "slow");
    // 2. 移動完後，字體再放大到 3em
    div.animate({fontSize: '3em'}, "slow");
});

動畫控制：停止、回呼函數與鏈式寫法

⚫ stop() 與 Callback 函數

  • stop() 用於在動畫完成前強制停止。
  • callback 是確保動畫 100% 完成後 才執行的程式碼。
// 停止目前正在進行的動畫
$("#stopBtn").click(function() {
    $("#panel").stop();
});

// Callback 範例：確保隱藏完畢才跳出警告
$("p").hide(1000, function() {
    alert("這個段落已經隱藏完成!");
});

⚫ 方法鏈接 (Chaining)

允許在同一個元素上連續呼叫多個 jQuery 指令，一條接著另一條，省去重複尋找元素的效能浪費。

// 鏈接技術：變更顏色 ➔ 向上滑動隱藏 ➔ 向下滑動顯示
// 程式碼可讀性高，且執行流暢
$("#p1").css("color", "red")
        .slideUp(2000)
        .slideDown(2000);
