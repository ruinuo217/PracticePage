Module 08: PHP 後端基礎

Server-side Scripting, Logic Control, Arrays & File Uploads

PHP 簡介與變數字串 (Introduction & Strings)

什麼是 PHP？它能做什麼？

⚫ PHP 簡介

  • 包含多元代碼： 檔案內可包含 HTML、JavaScript、以及 PHP 代碼。
  • 伺服器端執行： 代碼在伺服器上執行，結果會以純 HTML 形式返回給瀏覽器（使用者看不到 PHP 原始碼）。
  • 副檔名： 預設文件擴展名是 .php。

⚫ PHP 強大的能力

  • 可以生成動態頁面內容。
  • 可以建立、開啟、讀取、寫入、關閉伺服器上的文件。
  • 可以收集表單資料，並發送和接收 cookie。
  • 可以新增、刪除、修改資料庫中的資料。
  • 可以限制用戶訪問網站上的某些頁面（權限控管）。

開發環境與 VSCode 外掛

  • 建立網站 (XAMPP)： 於 c:\xampp\htdocs\ 內建立資料夾 (例如 \php)，即可透過 http://localhost/php/ 訪問該網站。

⚫ 推薦 VSCode 外掛

  • PHP Intelephense： 提供強大的 PHP 代碼提示與自動完成功能。
  • Open PHP/HTML/JS In Browser： 方便在瀏覽器中開啟檔案。需設定伺服器主目錄「Document Root Folder」(例如 c:\xampp\htdocs\)。

基本的 PHP 語法與註解

PHP 腳本可以放在 HTML 文檔中的任何位置，並以特定的標籤包覆。

<!-- PHP 腳本範圍 -->
<?php
    // 這是 PHP 單行註解

    /*
       這是
       PHP 多行註解
    */
?>

PHP 輸出字串 (Echo)

echo 是一個語言結構（非真正的函數），使用的時候可以不用加括號，也可以加上括號：echo 或 echo()。

<?php
    // 輸出字串 (可以包含 HTML 標籤)
    echo "<h1> Hello World </h1>";
    
    // 也可以輸出變數與字串的組合
    $name = "Reyna";
    echo "Welcome, " . $name . "!"; // 點 (.) 是 PHP 的字串連接符
?>

PHP 變數與資料型別 (Variables & Data Types)

PHP 是一種「弱型別」語言，變數不需要事先宣告資料型別，給予什麼值就會自動轉換成什麼型別。

⚫ 變數宣告與命名規則

  • 變數必須以 $ 符號開始，後面跟著變數的名稱。
  • 名稱必須以字母或底線開始。
  • 只能包含字母、數字以及底線 (A-z、0-9 和 _ )，不能包含空格。
  • 區分大小寫 ($y 和 $Y 是兩個不同的變數)。
<?php
    $userName = "Reyna"; // 字串
    $userAge = 25;       // 數字
    $_isLogin = true;    // 底線開頭也是合法的
    
    // $1name = "Test";  // ❌ 錯誤：不能以數字開頭
?>

⚫ 資料型別與 var_dump()

常見型別：整數 (支援16進位 0x 與8進位 0)、浮點數、布林 (true/false)、字串、物件、NULL。

💡 伺服器端除錯神器： var_dump() 函數會直接印出變數的「型別」與「長度/內容」，是後端開發找 Bug 必備的指令！ 
<?php
    $num = 25;
    $hexNum = 0x1A; // 16進位的 26
    $isReady = false;
    $emptyValue = NULL;

    // 檢視變數的詳細資訊
    var_dump($num);      // 輸出: int(25)
    var_dump($isReady);  // 輸出: bool(false)
?>

常數宣告與字串操作 (Constants & Strings)

常數用於儲存全站通用的設定，字串則用來處理文字輸出。

⚫ 常數宣告 (define vs const)

常數一旦設定後就不能更改，且名稱前方不加 $ 符號。

💡 Modern PHP 觀念：
除了傳統的 define()，現代 PHP 開發（尤其是接觸物件導向或框架時）更強烈建議使用 const 關鍵字宣告，語法更簡潔易讀！ 
<?php
    // 傳統寫法：define(名稱, 值)
    define("URL", "http://localhost/php/");
    echo URL;

    // 🌟 現代寫法：使用 const 關鍵字
    const MAX_USERS = 100;
    echo MAX_USERS;
?>

⚫ 字串串接與雙引號解析

計算長度使用 strlen()，字串相連使用點 . 符號。

💡 Modern PHP 觀念：字串插值 (Interpolation)
只要使用雙引號 ("")，就可以直接把變數寫在字串裡（建議加上大括號 {} 標示邊界），PHP 會自動解析它，不用再痛苦地寫一堆點和引號了！ 
<?php
    $name = "Reyna";

    // ⚠️ 傳統寫法：使用點 (.) 串接
    $greet1 = "Hello, " . $name . "!"; 
    
    // 🌟 現代推薦寫法：雙引號直接解析變數
    $greet2 = "Hello, {$name}!"; 

    // 計算字串長度
    echo strlen("Hello World"); // 回傳 11
?>

PHP 運算子 (Operators)

賦值與遞增/遞減運算子 (Assignment & Increment)

⚫ 賦值運算子

用於把右側的值（或運算結果）寫入左側的變數中。特別注意字串串接是用 .=。

運算子等同於描述
=x = y將右側的值設定給左側
+= / -=x = x + y加 / 減
*= / /=x = x * y乘 / 除
%=x = x % y取餘數
.=a = a . b連接兩個字串

⚫ 遞增與遞減運算子

主要用於迴圈計數。++x (先加再傳) 和 x++ (先傳再加) 在賦值時的結果會完全不同！

<?php
    $a = 5;
    // 後遞增 (x++)：先回傳原來的值，然後才 +1
    echo $a++; // 輸出 5，此時 $a 變成 6

    $b = 5;
    // 預遞增 (++x)：先 +1，然後才回傳新的值
    echo ++$b; // 輸出 6，此時 $b 變成 6
    
    // 遞減 (--x 與 x--) 的邏輯完全相同
?>

比較運算子 (Comparison Operators)

💡 Modern PHP 觀念：
1. 強烈建議使用 === (絕對等於)：PHP 會有奇妙的自動轉型，使用 == 容易產生 Bug（例如在舊版 PHP 中 "0" == false 會是 true）。
2. PHP 7 新增「太空船運算子 <=>」：非常適合用在陣列自訂排序上，取代繁瑣的 if/else 比對！
運算子名稱現代開發建議與描述實例 (x=5)
===絕對等於(推薦) 類型與值都必須完全相同，返回 true5 === "5" ➔ false
!==絕對不等於(推薦) 值不相等，或類型不同，返回 true5 !== "5" ➔ true
==等於(不推薦) 會自動轉換型別再比較5 == "5" ➔ true
!= / <>不等於(不推薦) 會自動轉換型別再比較5 != 8 ➔ true
> / <大於 / 小於大於 / 小於對方時返回 true5 < 8 ➔ true
>= / <=大於(小於)等於包含等於的條件判斷5 <= 8 ➔ true
<=>太空船運算子(PHP 7+) 左邊大於右邊回傳 1，等於回傳 0，小於回傳 -15 <=> 8 ➔ -1

邏輯與三元運算子 (Logical & Ternary Operators)

結合多個條件判斷，以及精簡 if...else 語法結構的必備利器。

⚫ 邏輯運算子與優先權陷阱

包含 && (與)、|| (或)、! (非)、xor (異或：僅有一個為true時才成立)。

⚠️ 避坑指南：&& vs and 的差異
雖然 && 和 and 都是「且」，但 && 的優先權高於 =，而 and 的優先權低於 =。實務上請一律使用符號 && 和 || 以避免指派錯誤。 
<?php
    // 正確的邏輯判斷使用符號
    $x = 6;
    $y = 3;
    if ($x < 10 && $y > 1) {
        echo "兩者皆成立！";
    }

    // 優先權陷阱示範
    $a = true && false; // $a 為 false
    $b = true and false; // $b 為 true (因為先執行了 $b = true)
?>

⚫ 現代精簡條件判斷

用來取代冗長的 if...else，現代 PHP 有三種超實用的縮寫方式：

<?php
    // 1. 三元運算子 (Ternary) - 基礎款
    $sex = '男';
    echo ($sex == '女') ? '小姐' : '先生'; // 輸出: 先生

    // 2. 🌟 貓王運算子 (Elvis) - PHP 5.3+
    // 如果左邊是 true (有值)，就用左邊；否則用右邊
    $userName = $_GET['user'] ?: '訪客';

    // 3. 🌟 Null 合併運算子 (Null Coalescing) - PHP 7+
    // 專門對付未定義變數！如果左邊存在且不是 Null 就用左邊
    // (現代實務上接 GET/POST 參數必用)
    $page = $_GET['page'] ?? 1; 
?>

邏輯判斷與迴圈控制 (Logic & Loops)

條件判斷：If / Else 判斷式

當需要為不同的判斷執行不同的動作時，可以使用條件語句來控制程式的走向。

💡 Modern PHP 觀念：樣板替代語法
前端開發者在寫 PHP 視圖 (View) 時，經常需要把 HTML 和 PHP 混在一起寫。為了避免大括號 {} 造成閱讀困難，現代實務強烈推薦使用「替代語法」（以 : 取代 {，並以 endif; 結尾）。

⚫ 基礎 If 與 If...Else

條件成立時執行 A，不成立時執行 B。

<?php
    $t = date("H"); // 取得目前的小時 (00~23)

    // 1. 單一 if 判斷
    if ($t < 20) {
        echo "Have a good day!<br>";
    }

    // 2. if...else 判斷
    if ($t < 20) {
        echo "目前還沒晚上 8 點喔！";
    } else {
        echo "Have a good night!";
    }
?>

⚫ If...Elseif...Else 與替代語法

用於多重條件判斷。下方示範實務上與 HTML 混寫的現代寫法。

<!-- 🌟 現代實戰寫法：替代語法 (Alternative Syntax) -->
<?php $t = date("H"); ?>

<div class="greeting-box">
    <?php if ($t < 10): ?>
        <h2>Have a good morning!</h2>
        
    <?php elseif ($t < 20): ?>
        <h2>Have a good day!</h2>
        
    <?php else: ?>
        <h2>Have a good night!</h2>
        
    <?php endif; ?> <!-- 清楚標示判斷式結束 -->
</div>

多重條件判斷：Switch 與 Match (PHP 8+)

當遇到「單一變數」需要比對「多種特定值」時，這類語法比寫一長串的 if...elseif 更簡潔。

💡 Modern PHP 觀念：擁抱 match 表達式
傳統的 switch 存在幾個痛點：比對時是鬆散比對 (==) 容易出錯，且忘記寫 break 會導致程式「穿透」繼續往下跑。PHP 8 引入了 match，它預設嚴格比對 (===)、不用寫 break，而且可以直接把結果賦值給變數，是現代 PHP 開發的首選！

⚫ 傳統 Switch 判斷式

注意每一個 case 結束都必須加上 break;。

<?php
    $favcolor = "red";

    switch($favcolor) {
        case "red":
            echo "你喜歡的顏色是紅色！";
            break;
        case "blue":
            echo "你喜歡的顏色是藍色！";
            break;
        case "green":
            echo "你喜歡的顏色是綠色！";
            break;
        default:
            echo "你喜歡的顏色不是紅、藍或綠色！";
    }
?>

⚫ 🌟 現代 PHP 8 Match 表達式

語法極度精簡，且比對安全。實務上大推！

<?php
    $favcolor = "red";

    // match 會直接把結果「回傳」，所以可以直接賦值給變數
    $result = match($favcolor) {
        "red" => "你喜歡的顏色是紅色！",
        "blue" => "你喜歡的顏色是藍色！",
        "green" => "你喜歡的顏色是綠色！",
        default => "你喜歡的顏色不是紅、藍或綠色！",
    };

    echo $result;
?>

計次迴圈：For 與替代語法

當你「已經知道」程式區塊需要重複執行的明確次數時，最適合使用 for 迴圈。

💡 Modern PHP 觀念：樣板替代語法
與 if 判斷式一樣，迴圈在與 HTML 混寫時，也非常推薦使用「替代語法」（例如 for...endfor;），讓 HTML 結構維持乾淨清晰。同時記得多利用雙引號變數解析，取代傳統的字串相加。

⚫ 基礎 For 迴圈

<?php
    // 括號內依序為：(初始值 ; 繼續執行的條件 ; 每次執行後的動作)
    for ($i = 1; $i <= 5; $i++) {
        // 🌟 現代寫法：使用雙引號直接解析變數
        echo "數字為 {$i} <br>";
    }
?>

⚫ For 替代語法 (結合 HTML)

實戰常用：動態在網頁上印出多個 HTML 區塊。

<div class="item-list">
    <!-- 使用冒號 : 開頭 -->
    <?php for ($i = 1; $i <= 3; $i++): ?>
        
        <div class="item">
            這是第 <?php echo $i; ?> 個項目
        </div>
        
    <?php endfor; ?> <!-- 使用 endfor; 結尾 -->
</div>

條件迴圈：While 與 Do...While

當你「不確定執行次數」，只要條件成立就一直跑時，使用 while 系列迴圈。

⚫ While 迴圈

「先檢查，後執行」：條件成立才執行代碼。如果一開始就不成立，可能一次都不會執行。

<?php
    $i = 1;
    while ($i <= 5) {
        echo "The number is {$i} <br>";
        $i++; // ⚠️ 記得要遞增，否則會變成無限迴圈！
    }

    // 🌟 While 的替代語法
    /* while ($i <= 5):
        // 執行代碼
    endwhile; 
    */
?>

⚫ Do...While 迴圈

「先執行，後檢查」：先執行一次代碼區塊，然後再檢查條件。因此無論如何至少會執行一次。

<?php
    $j = 1;
    do {
        // 先無條件執行一次
        echo "The number is {$j} <br>";
        $j++;
    } while ($j <= 5);
    
    // 測試：即使初始條件不成立
    $k = 10;
    do {
        echo "條件不成立，但我還是會印出這行！";
    } while ($k <= 5);
?>

迴圈進階控制：Break 與 Continue

在迴圈執行過程中，我們經常需要根據特定條件「強制提早結束」或「跳過這回合」。

⚫ Break (中斷並跳出)

遇到 break 會直接中斷，並結束整個迴圈。

<?php
    for ($i = 1; $i <= 10; $i++) {
        if ($i == 4) {
            break; // 遇到 4 時，直接跳出整個迴圈
        }
        echo "數字: {$i} | ";
    }
    // 結果只會印出：數字: 1 | 數字: 2 | 數字: 3 | 
?>

⚫ Continue (跳過本次)

遇到 continue 會中斷「這一次」的迴圈，直接進入下一次的迴圈判斷。

<?php
    for ($i = 1; $i <= 5; $i++) {
        if ($i == 3) {
            continue; // 遇到 3 時跳過，不往下執行
        }
        echo "數字: {$i} | ";
    }
    // 結果會印出：數字: 1 | 數字: 2 | 數字: 4 | 數字: 5 | 
?>

陣列操作 (Arrays)

PHP 陣列基礎與數值陣列 (Indexed Arrays)

陣列能在一個變數中儲存多個值。PHP 有三種陣列：數值陣列 (以數字為索引)、關聯陣列 (自訂鍵值)、多維陣列 (陣列包陣列)。

💡 Modern PHP 觀念：短陣列語法 (Short Array Syntax)
傳統講義會使用 array() 函數來創建陣列，但現代 PHP 開發已經全面改用更簡潔的中括號 []，強烈建議直接習慣現代寫法！

⚫ 宣告陣列：傳統 vs 現代寫法

<?php
    // ⚠️ 傳統寫法：使用 array()
    $carsOld = array("Volvo", "BMW", "Toyota");

    // 🌟 現代寫法：使用短陣列語法 []
    $cars = ["Volvo", "BMW", "Toyota"];
    
    // 陣列可以混裝不同型別的資料
    $mixedArray = ["Reyna", 25, true, 3.14];
?>

⚫ 數值陣列 (Indexed Arrays)

帶有數字索引的陣列。索引值預設是從 0 開始計算。

<?php
    $cars = ["Volvo", "BMW", "Toyota"];

    // 透過索引值取得陣列內容
    echo $cars[0]; // 輸出 Volvo
    echo $cars[1]; // 輸出 BMW
    echo $cars[2]; // 輸出 Toyota

    // 修改陣列元素
    $cars[0] = "Ford"; 

    // 在陣列最後面新增一個元素
    $cars[] = "Honda"; 
?>

關聯陣列 (Associative Arrays)

關聯陣列是帶有「自訂鍵值 (Key)」的陣列，每個鍵會關聯一個「值 (Value)」。這種結構等同於 JavaScript 中的「物件 (Object)」，非常適合用來儲存單筆詳細資料（如使用者個資）。

⚫ 宣告與讀取關聯陣列

使用 => 符號來指定鍵與值的對應關係。

<?php
    // 🌟 現代寫法：定義關聯陣列
    $user = [
        "name"  => "Peter",
        "age"   => 35,
        "email" => "peter@test.com"
    ];

    // 透過自訂的鍵名 (Key) 來取得值
    echo $user['name']; // 輸出 Peter
    echo $user['age'];  // 輸出 35

    // 修改特定鍵的值
    $user['age'] = 36;
?>

⚫ 搭配 foreach 迴圈遍歷

foreach 是專門用來跑陣列的迴圈，可以同時把 Key 和 Value 抓出來。

<?php
    $ages = ["Peter"=>"35", "Ben"=>"37", "Joe"=>"43"];

    // 語法：foreach ($陣列變數 as $鍵名 => $值)
    foreach ($ages as $name => $age) {
        // 搭配雙引號變數解析，寫法極度簡潔
        echo "姓名: {$name}，年齡: {$age} <br>";
    }
?>

多維陣列與巢狀迴圈 (Multidimensional Arrays)

包含一個或多個陣列的陣列。這在後端開發極度常見，當你從資料庫抓出「多筆商品」或「多個使用者」資料時，回傳的就是多維陣列。

⚫ 定義與讀取多維陣列

陣列裡面的元素也是陣列，需要使用多個中括號來存取對應層級的資料。

<?php
    // 陣列中包著三個陣列：[品牌, 庫存, 銷量]
    $cars = [
        ["Volvo", 100, 96],
        ["BMW", 60, 59],
        ["Toyota", 110, 100]
    ];

    // 讀取第一筆 (Volvo) 的庫存 (100)
    // $cars[0] 抓到第一列，接著 [1] 抓到該列的第二個元素
    echo $cars[0][1]; 

    // 讀取第二筆 (BMW) 的銷量 (59)
    echo $cars[1][2]; 
?>

⚫ 搭配巢狀 foreach 遍歷資料

使用雙層迴圈，把外層與內層的資料全部印出來（常用於產生 HTML 表格 <table>）。

<?php
    $cars = [
        ["Volvo", 100, 96],
        ["BMW", 60, 59],
        ["Toyota", 110, 100]
    ];

    // 第一層：跑過每一列 (每一台車的資料陣列)
    foreach ($cars as $carRow) {
        
        // 第二層：跑過該列裡面的每一個具體數值
        foreach ($carRow as $value) {
            echo "{$value} | ";
        }
        
        echo "<br>"; // 每跑完一台車就換行
    }
?>

表單處理與檔案上傳 (Forms & Uploads)

GET 變數與網址傳遞 ($_GET)

用於收集來自 method="get" 的表單值，或是直接附加在網址後方的參數。

💡 GET 的特性與使用時機：
1. 可見性： 傳送的資料會以 ?key=value 的形式顯示在瀏覽器的網址列，對任何人都是可見的。
2. 限制： 網址長度有限制（大約 2000 個字元），不能傳送過多的資料。
3. 適用情境： 適合用在沒有安全性考量且需要被分享或加入書籤的操作，例如：搜尋關鍵字、文章分頁、商品篩選條件。

⚫ 前端 HTML 表單

<!-- 表單發送後，網址會變成：
     search.php?keyword=蘋果 -->
<form action="search.php" method="get">
    搜尋：<input type="text" name="keyword">
    <input type="submit" value="送出">
</form>

<!-- 也可以直接寫在超連結上 -->
<a href="search.php?keyword=蘋果">搜尋蘋果</a>

⚫ 後端 PHP 接收 ($_GET)

使用 PHP 內建的超全域變數 $_GET 陣列來接收。

<?php
    // 透過表單的 name 屬性 (keyword) 來取得對應的值
    $searchKey = $_GET["keyword"];
    
    // ⚠️ 警告：這只是基礎示範。
    // 在現代實務中直接這樣寫會有報錯風險與資安漏洞，
    // 請看下方的「安全防護」卡片說明！
?>

POST 變數與隱藏傳遞 ($_POST)

用於收集來自 method="post" 的表單值。資料會被打包在 HTTP 請求的 Body 裡面傳送。

💡 POST 的特性與使用時機：
1. 隱蔽性： 傳送的資訊對任何人都是不可見的（不會顯示在網址列）。
2. 無長度限制： 可以傳送大量的資料。
3. 適用情境： 適合傳送敏感資訊（如密碼、身分證字號）或大型檔案（如圖片上傳、長篇大論的文章內容）。

⚫ 前端 HTML 表單

<!-- 表單發送後，網址依然是 login.php，
     密碼不會暴露在網址列 -->
<form action="login.php" method="post">
    帳號：<input type="text" name="user"><br>
    密碼：<input type="password" name="pwd"><br>
    <input type="submit" value="登入">
</form>

⚫ 後端 PHP 接收 ($_POST)

<?php
    // 透過 $_POST 陣列接收隱藏傳遞的資料
    $account = $_POST["user"];
    $password = $_POST["pwd"];
?>

💡 現代實戰與安全防護 (Modern Security & Syntax)

在現代 PHP 8+ 開發中，接收表單與輸出資料必須遵守以下兩大黃金守則。

⚫ 1. 防範未定義報錯 (Null Coalescing)

如果使用者直接進入網頁（沒送出表單），直接抓取 $_POST['user'] 會引發錯誤。現代 PHP 強烈建議使用 ?? 給予預設值。

<?php
    // 🌟 現代寫法：如果左邊不存在，就套用右邊的預設值
    $account = $_POST["user"] ?? "未輸入帳號";
    
    // 如果是分頁，預設為第一頁
    $page = $_GET["page"] ?? 1;
?>

⚫ 2. 防範 XSS 攻擊 (跨站腳本攻擊)

絕對不要直接 echo 使用者輸入的內容！駭客可以輸入 <script> 標籤來植入惡意程式。輸出前必須「消毒」。

<?php
    $searchKey = $_GET["keyword"] ?? "";

    // ⚠️ 極度危險 (會被植入惡意腳本)
    // echo "您搜尋了：" . $searchKey;

    // 🌟 現代寫法：使用 htmlspecialchars() 轉換特殊字元
    // 這會把 < 轉換成 &lt; 讓腳本失效
    $safeInput = htmlspecialchars($searchKey, ENT_QUOTES);
    echo "您搜尋了：{$safeInput}";
?>

表單設定與 $_FILES 陣列 (Form & $_FILES)

要透過 PHP 接收檔案，前端表單必須具備特定屬性，而後端則透過 $_FILES 這個超級全域變數 (二維陣列) 來接收。

💡 前端表單的硬性規定：
要上傳檔案，表單的 method 必須是 POST，而且必須加上 enctype="multipart/form-data"，否則 PHP 完全收不到檔案實體！

⚫ 前端 HTML 表單

<!-- enctype 屬性絕對不能漏掉！ -->
<form action="upload.php" method="post" enctype="multipart/form-data">
    <label for="file">選擇檔案：</label>
    <!-- name 屬性決定了後端接收的鍵值 -->
    <input type="file" name="myFile" id="file" required>
    <button type="submit">上傳檔案</button>
</form>

⚫ 後端 $_FILES 五大屬性

  • ["name"]：上傳檔案的原始名稱 (如 image.jpg)。
  • ["type"]：檔案的 MIME 類型 (如 image/jpeg)。
  • ["size"]：檔案大小 (單位為 bytes)。
  • ["tmp_name"]：檔案上傳後，暫存在伺服器上的臨時路徑與名稱。
  • ["error"]：錯誤代碼 (0 代表成功無錯誤)。

基礎檔案上傳實作 (Basic Upload Logic)

檔案上傳後會先放在伺服器的「暫存區」，我們必須使用 move_uploaded_file() 將它移動到指定的正式目錄中。

⚫ 檢查與讀取檔案資訊

現代寫法會使用 PHP 內建的常數 UPLOAD_ERR_OK (其值為 0) 來判斷是否上傳成功。

<?php
    // 先確認是否有收到名為 myFile 的檔案
    if (isset($_FILES["myFile"])) {
        
        $file = $_FILES["myFile"];
        
        // 檢查是否有上傳錯誤
        if ($file["error"] === UPLOAD_ERR_OK) {
            $fileName = $file["name"];
            $fileTmp  = $file["tmp_name"];
            
            // 換算為 KB 顯示
            $fileSizeKB = round($file["size"] / 1024, 2);
            echo "檔案 {$fileName} ({$fileSizeKB} KB) 已成功抵達暫存區。";
            
        } else {
            echo "上傳發生錯誤，代碼：" . $file["error"];
        }
    }
?>

⚫ 移動檔案至指定目錄

暫存檔在 PHP 腳本執行結束後就會自動刪除，因此必須立刻移動。

<?php
    // ...接續左側的成功判斷邏輯...

    // 設定要儲存的目標資料夾 (確保該資料夾已建立且有寫入權限)
    $uploadDir = "uploads/";
    
    // 目標檔案的完整路徑 (資料夾路徑 + 檔名)
    $destination = $uploadDir . $fileName;

    // 將檔案從暫存區移動到目標位置
    if (move_uploaded_file($fileTmp, $destination)) {
        echo "檔案已成功儲存至：{$destination}";
    } else {
        echo "檔案移動失敗！";
    }
?>

💡 現代後端必備：檔案上傳安全防護 (Security Practices)

絕對不能直接信任使用者的原始檔名 (可能包含惡意代碼或覆蓋現有檔案)。實戰中，我們必須自行檢查副檔名、限制大小，並給予亂數新檔名！

⚫ 1. 限制大小與驗證副檔名

<?php
    $file = $_FILES["myFile"];
    $maxSize = 2 * 1024 * 1024; // 限制 2MB (2 * 1024KB * 1024Bytes)

    // 檢查檔案大小
    if ($file["size"] > $maxSize) {
        die("檔案太大，請上傳小於 2MB 的檔案！");
    }

    // 取得並檢查副檔名 (將檔名轉小寫並取得最後一個小數點後的值)
    $fileExt = strtolower(pathinfo($file["name"], PATHINFO_EXTENSION));
    $allowedExts = ["jpg", "jpeg", "png", "gif"];

    // 判斷副檔名是否在白名單內
    if (!in_array($fileExt, $allowedExts)) {
        die("只允許上傳 JPG, PNG, GIF 圖片檔！");
    }
?>

⚫ 2. 重新命名機制 (防止覆蓋與資安漏洞)

使用時間戳或 uniqid() 產生獨一無二的檔名，再接回原本安全的副檔名。

<?php
    // ...接續左側通過檢查後的邏輯...

    // 產生唯一新檔名 (例如: 6512a3b9c7d8e.jpg)
    $newFileName = uniqid() . "." . $fileExt;
    
    // 設定新的儲存路徑
    $uploadDir = "uploads/";
    $destination = $uploadDir . $newFileName;

    // 安全地移動檔案
    if (move_uploaded_file($file["tmp_name"], $destination)) {
        echo "上傳成功！新檔名為：{$newFileName}";
    }
?>
