Server-side Scripting, Logic Control, Arrays & File Uploads

PHP 簡介與變數字串 (Introduction & Strings)

什麼是 PHP？

  • 伺服器端腳本： 代碼在伺服器上執行，最終以純 HTML 形式返回給瀏覽器。
  • 動態能力： 能生成動態頁面內容、收集表單資料，以及與資料庫互動。
  • 副檔名： 預設為 .php。

變數、常數與字串

使用 $ 宣告變數，define() 宣告常數，並用 . 符號串接字串。

<?php
    // 變數宣告與常數
    $userName = "Reyna"; 
    define("URL", "http://localhost/php/"); 

    // 字串串接 (使用 .)
    $greeting = "Hello " . $userName;
    echo $greeting;

    // 計算字串長度
    echo strlen("Hello World"); // 回傳 11
?>

邏輯判斷與迴圈控制 (Logic & Loops)

條件判斷 (If & Switch)

透過條件判斷來控制程式走向。簡易判斷可使用三元運算子 ?:。

<?php
    $t = date("H");

    // if...elseif...else 判斷式
    if ($t < 10) {
        echo "Good morning!";
    } elseif ($t < 20) {
        echo "Good day!";
    } else {
        echo "Good night!";
    }

    // Switch 判斷式
    $favcolor = "red";
    switch($favcolor) {
        case "red":
            echo "你喜歡紅色";
            break;
        default:
            echo "你喜歡其他顏色";
    }

    // 三元運算子
    $sex = '男';
    echo ($sex == '女') ? '小姐' : '先生';
?>

迴圈控制 (For, While, Do...While)

讓相同的代碼區塊重複運行。依據是否已知執行次數來選擇合適的迴圈。

<?php
    // for 迴圈 (執行指定次數)
    for( $i = 1 ; $i <= 5 ; $i++ ) {
        echo "數字為 " . $i . "<br>";
    }

    // while 迴圈 (條件成立時執行)
    $j = 1;
    while($j <= 5) {
        echo "The number is " . $j . "<br>";
        $j++;
    }

    // do...while 迴圈 (至少執行一次)
    $k = 1;
    do {
        echo "Do Loop: " . $k;
        $k++;
    } while($k <= 5);
?>

陣列操作 (Arrays)

數值、關聯與多維陣列

PHP 陣列支援數字索引、自訂鍵值 (Key)，甚至可以在陣列中包覆陣列 (多維陣列)。

<?php
    // 1. 數值陣列
    $cars = array("Volvo", "BMW", "Toyota");

    // 2. 關聯陣列 (指定鍵值)
    $age = array("Peter"=>"35", "Ben"=>"37");
    echo $age['Peter']; // 輸出 35

    // 3. 多維陣列 (陣列中的陣列)
    $stock = array (
        array("Volvo", 100, 96),
        array("BMW", 60, 59)
    );
?>

foreach 陣列遍歷

foreach 是專門用來處理陣列的迴圈。處理多維陣列時可使用雙層巢狀結構。

<?php
    $cars = array("Volvo", "BMW", "Toyota");

    // 遍歷單維陣列
    foreach($cars as $value) {
        echo $value . "<br>";
    }

    // 遍歷多維陣列 (巢狀 foreach)
    $multi_cars = array(
        array("Volvo", 100),
        array("BMW", 60)
    );
    foreach($multi_cars as $x) {
        foreach($x as $y) {
            echo $y . ' ';
        }
        echo '<br>';
    }
?>

表單處理與檔案上傳 (Forms & Uploads)

GET 與 POST 變數

💡 重點：
$_GET 參數顯示在網址列，有長度限制。
$_POST 不顯示於網址列，較安全且無長度限制。 
<?php
    // 取得網址列參數 (?username=...)
    $user = $_GET["username"];

    // 取得隱藏傳遞的表單資料
    $pwd = $_POST["userpassword"];
?>

實戰：檔案上傳處理

前端需設定 enctype="multipart/form-data"。後端透過 $_FILES 接收並移動檔案。

<!-- 1. 前端 HTML 表單 -->
<form action="upload.php" method="post" enctype="multipart/form-data">
    <input type="file" name="file" id="file">
    <input type="submit" name="submit" value="提交">
</form>

<!-- 2. 後端 PHP 處理 (upload.php) -->
<?php
    if ($_FILES["file"]["error"] > 0) {
        echo "錯誤: " . $_FILES["file"]["error"];
    } else {
        echo "檔案名稱: " . $_FILES["file"]["name"];
        echo "檔案大小: " . ($_FILES["file"]["size"] / 1024) . " kB";
        
        // 將檔案從暫存區移動到指定目錄
        move_uploaded_file(
            $_FILES["file"]["tmp_name"], 
            "upload/" . $_FILES["file"]["name"]
        );
    }
?>
