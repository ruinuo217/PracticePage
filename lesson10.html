API 概念與應用場景 (Concepts)

[Image of RESTful API client server architecture]

何謂 Web API？

  • API (應用程式介面)： 就像是餐廳的服務生（信差），接收前端的要求，傳遞給後端廚房，再把資料（餐點）送回前端。能大幅減少開發成本。
  • Web API： 藉由 HTTP 通訊協定，進行請求、運算、回應的 API。通常提供 JSON 或 XML 兩種傳輸格式，是現代網頁交換資訊的基礎。

常見 Web API 應用場景

透過串接第三方或自己建立的 API，能為網站擴充強大的功能：

  • 會員認證： 串接 Google、Facebook 社群帳號快速登入。
  • 社群嵌入： 臉書分享、按讚按鈕整合。
  • 資料嵌入： Google Maps 地圖、天氣資訊、即時匯率等。

資料傳輸格式 (XML vs JSON)

舊式標準：XML 格式

使用類似 HTML 的標籤包覆資料，缺點是較為冗長，增加傳輸體積。

<robot>
    <name>多拉A夢</name>
    <height>129.3</height>
    <weight>129.3</weight>
    <hobby>
        <food>銅鑼燒、機油</food>
        <relationship>和小咪約會</relationship>
    </hobby>
</robot>

現代主流：JSON 格式

JSON 更輕量、靈活且可讀性極高。它幾乎與所有網頁語言相容，是目前 Web API 最普遍的格式。

{
    "name": "多拉A夢",
    "height": 129.3,
    "weight": 129.3,
    "hobby": {
        "food": "銅鑼燒、機油",
        "relationship": "和小咪約會"
    }
}

前後端串接實作 (AJAX & PHP Endpoints)

前端：使用 jQuery AJAX 請求資料

💡 非同步傳輸：
使用 AJAX 可以在「不重新整理網頁」的情況下，與伺服器交換資料並更新部分網頁內容。 
// 1. 簡易的 GET 請求 (取得資料)
$.get("demo.json", function(result) {
    console.log(result);
});

// 2. 完整的 POST 請求 (傳送表單與上傳檔案)
let formData = new FormData();
formData.append('guest', $('#guest').val());
formData.append('photo', $('#photo')[0].files[0]);

$.ajax({
    url: 'api_url.php',
    type: 'POST',
    data: formData,
    contentType: false, // 必須為 false 才能傳送檔案
    processData: false, // 必須為 false 避免資料被轉換
    success: function(returnData) {
        console.log(returnData);
    }
});

後端：使用 PHP 製作 Web API

PHP 接收請求、操作資料庫後，最重要的步驟就是將陣列使用 json_encode() 轉換成 JSON 字串輸出。

<?php
    // --- 實作：新增資料並回傳 JSON 結果 ---
    $sql = "INSERT INTO table VALUES('$user', '$file')";
    
    // 初始化回傳陣列
    $arr = array(); 

    if (mysqli_query($conn, $sql)) {
        $arr['success'] = true;
        $arr['message'] = '資料傳送成功';
    } else {
        $arr['success'] = false;
        $arr['message'] = '資料傳送失敗';
    }

    // 將陣列轉為 JSON 格式 (保留中文不轉譯)
    $api = json_encode($arr, JSON_UNESCAPED_UNICODE);
    
    // 輸出 API 回應給前端
    echo $api;
?>
