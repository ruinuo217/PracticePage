網格系統與斷點 (Grid System & Breakpoints)

容器與斷點基礎

  • 六個斷點： X-Small, sm, md, lg, xl, xxl。響應式開發以行動版為優先。
  • 容器 (Container)：
    • .container：每個斷點會設置固定的 max-width。
    • .container-fluid：所有斷點寬度都是 100%。

12 欄網格與間距 (Gutters)

網格必須放在 .container 中，並使用 .row 創建列。每行最多 12 欄。

  • 欄位： .col-4 代表跨越四欄。
  • Gutters (欄溝)： 控制 margin 和 padding 間隔。可用 .gx-* (水平)、.gy-* (垂直)、.g-* (全部)、.g-0 (移除)。

偏移欄 (Offset)

通過 .offset-*-* 把列往右推移。第一個 * 為設備斷點，第二個 * 為 1~11 的數字。

<!-- 在 md 螢幕以上，佔 4 格，並向右位移 4 格 -->
<div class="col-md-4 offset-md-4">置中文字或區塊</div>

公用類別 (Utility Classes)

間隔命名規則 (Spacing)

格式為 {property}{sides}-{size}。

  • Property： m (margin), p (padding)
  • Sides： t(top), b(bottom), s(start/左), e(end/右), x(左右), y(上下), 空白(四邊)
  • Size： 0 (0), 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem), auto

邊框與圓角 (Borders)

快速為元素添加邊框、設定色彩與調整圓角。

<!-- 邊框顯示與移除 -->
<span class="border"></span>
<span class="border border-0"></span> <!-- 移除四邊邊框 -->
<span class="border-top-0"></span>

<!-- 邊框色彩 -->
<span class="border border-primary"></span>
<span class="border border-danger"></span>

<!-- 圓角設定 -->
<span class="rounded"></span>
<span class="rounded-top"></span>
<span class="rounded-circle"></span> <!-- 正圓形 -->

寬高、浮動與居中對齊 (Sizing & Alignment)

💡 BS5 語法更新提醒： 左右浮動已從 float-left / right 變更為 float-start / end。 
<!-- 寬度與高度 (可用級別: 25, 50, 75, 100, auto) -->
<div class="w-50 h-50">寬 50%，高 50%</div>
<div class="mw-100 mh-100">最大寬度與高度 100%</div>

<!-- 水平置中 (需有指定寬度) -->
<div class="mx-auto" style="width:150px">置中顯示</div>

<!-- 浮動與清除浮動 -->
<div class="clearfix">
    <span class="float-start">靠左浮動</span>
    <span class="float-end">靠右浮動</span>
</div>

標題與 Display 標題

⚫ 標題

  • <h1></h1> 2.5rem = 40px
  • <h2></h2> 2rem = 32px
  • <h3></h3> 1.75rem = 28px
  • <h4></h4> 1.5rem = 24px
  • <h5></h5> 1.25rem = 20px
  • <h6></h6> 1rem = 16px

⚫ Display 標題類

一般的標題元素能在頁面內容繁多時發揮最佳作用。當你需要突出一個標題時，請考慮使用 display heading 以獲得更大、更細、稍具有風格化的標題樣式：

  • <h1 class="display-1">Display 1</h1> = 80px
  • <h1 class="display-2">Display 2</h1> = 72px
  • <h1 class="display-3">Display 3</h1> = 64px
  • <h1 class="display-4">Display 4</h1> = 56px
  • <h1 class="display-5">Display 5</h1> = 48px
  • <h1 class="display-6">Display 6</h1> = 40px

基礎元件 (Basic Components)

按鈕 (Buttons) 與按鈕組

Bootstrap 5 提供了不同樣式的按鈕，按鈕類可用於 <a>, <button>, 或 <input> 元素上。

⚫ 基本按鈕與框線樣式

<!-- 基本按鈕 -->
<button type="button" class="btn">基本按鈕</button>
<button type="button" class="btn btn-primary">主要按鈕</button>
<button type="button" class="btn btn-secondary">次要按鈕</button>
<button type="button" class="btn btn-success">成功</button>
<!-- 其他色彩依此類推: info, warning, danger, dark, light -->

<!-- 框線樣式的按鈕 -->
<button type="button" class="btn btn-outline-primary">主要按鈕</button>
<button type="button" class="btn btn-outline-secondary">次要按鈕</button>
<button type="button" class="btn btn-outline-success">成功</button>
<!-- 其他色彩依此類推: info, warning, danger, dark, light -->

⚫ 不同大小、狀態與滿版按鈕

💡 BS5 語法更新提醒： 已移除 .btn-block，滿版按鈕請直接加上 .w-100。 
<!-- 大小控制 -->
<button type="button" class="btn btn-primary btn-lg">大號按鈕</button>
<button type="button" class="btn btn-primary">預設按鈕</button>
<button type="button" class="btn btn-primary btn-sm">小號按鈕</button>

<!-- 滿版按鈕 (BS5 寫法) -->
<button type="button" class="btn btn-primary w-100">按鈕</button>

<!-- 點擊與禁用狀態 -->
<button type="button" class="btn btn-primary active">點擊後的按鈕</button>
<button type="button" class="btn btn-primary" disabled>禁止點擊的按鈕</button>

⚫ 水平與垂直按鈕組

在 <div> 添加 .btn-group。可使用 .btn-group-lg/sm 控制大小，或 .btn-group-vertical 轉為垂直。

<!-- 基礎按鈕組 -->
<div class="btn-group">
    <button type="button" class="btn btn-primary">Apple</button>
    <button type="button" class="btn btn-primary">Samsung</button>
    <button type="button" class="btn btn-primary">Sony</button>
</div>

<!-- 垂直按鈕組 -->
<div class="btn-group-vertical">
    <button type="button" class="btn btn-primary">Apple</button>
    <button type="button" class="btn btn-primary">Samsung</button>
    <button type="button" class="btn btn-primary">Sony</button>
</div>

⚫ 內嵌下拉選單按鈕組

💡 BS5 語法更新提醒： 觸發屬性需加上 bs，改為 data-bs-toggle="dropdown"。 
<div class="btn-group">
    <!-- 下拉觸發按鈕 -->
    <button type="button" class="btn btn-primary dropdown-toggle" data-bs-toggle="dropdown">
        Sony
    </button>
    
    <!-- 下拉選單內容 (BS5 建議使用 ul li) -->
    <ul class="dropdown-menu">
        <li><a class="dropdown-item" href="#">Tablet</a></li>
        <li><a class="dropdown-item" href="#">Smartphone</a></li>
    </ul>
</div>

徽章 (Badges)

主要用於突出顯示新的或未讀的項目。如需使用徽章，只需要將 .badge 類搭配帶有指定意義的背景色彩類 (如 .bg-primary) 添加到 <span> 元素上即可。

💡 BS5 語法更新提醒： BS5 已經移除了 .badge-* 色彩類別與 .badge-pill。現在設定顏色需直接使用 .bg-* (背景公用類別)，藥丸形狀則改用 .rounded-pill。

⚫ 基礎與各種顏色的徽章

<!-- BS5 使用 bg-* 來設定徽章顏色 -->
<span class="badge bg-primary">主要</span>
<span class="badge bg-secondary">次要</span>
<span class="badge bg-success">成功</span>
<span class="badge bg-danger">危險</span>
<!-- 淺色背景建議加上 text-dark 以免文字看不清楚 -->
<span class="badge bg-warning text-dark">警告</span>
<span class="badge bg-info text-dark">信息</span>
<span class="badge bg-light text-dark">淺色</span>
<span class="badge bg-dark">深色</span>

⚫ 藥丸形狀與內嵌徽章

<!-- 藥丸形狀徽章：使用 .rounded-pill -->
<span class="badge rounded-pill bg-secondary">默認</span>
<span class="badge rounded-pill bg-primary">主要</span>
<span class="badge rounded-pill bg-success">成功</span>
<span class="badge rounded-pill bg-info text-dark">信息</span>
<span class="badge rounded-pill bg-warning text-dark">警告</span>
<span class="badge rounded-pill bg-danger">危險</span>

<!-- 徽章插入到按鈕元素內 -->
<button type="button" class="btn btn-primary">
    Messages <span class="badge bg-light text-dark">4</span>
</button>

分頁導航 (Pagination)

要創建一個基本的分頁，可以在 <ul> 元素上添加 .pagination 類。然後在 <li> 元素上添加 .page-item 類，連結元素則加上 .page-link 類。

⚫ 基礎分頁與當前頁面 (Active)

當前頁可以使用 .active 類來高亮顯示：

<ul class="pagination">
    <li class="page-item"><a class="page-link" href="#">Previous</a></li>
    <li class="page-item"><a class="page-link" href="#">1</a></li>
    <!-- 當前高亮顯示 -->
    <li class="page-item active"><a class="page-link" href="#">2</a></li>
    <li class="page-item"><a class="page-link" href="#">3</a></li>
    <li class="page-item"><a class="page-link" href="#">Next</a></li>
</ul>

⚫ 不可點擊的分頁連結 (Disabled)

.disabled 類可以設置分頁連結為不可點擊狀態：

<ul class="pagination">
    <!-- 禁用狀態 -->
    <li class="page-item disabled"><a class="page-link" href="#">Previous</a></li>
    <li class="page-item"><a class="page-link" href="#">1</a></li>
    <li class="page-item"><a class="page-link" href="#">2</a></li>
    <li class="page-item"><a class="page-link" href="#">3</a></li>
    <!-- 另一端禁用 -->
    <li class="page-item disabled"><a class="page-link" href="#">Next</a></li>
</ul>

列表群組 (List Group)

⚫ 基礎列表與連結列表

在 <ul> 添加 .list-group，<li> 添加 .list-group-item。若要建立可點擊的連結清單，改用 <div> 與 <a>，並加上 .list-group-item-action 實現懸停顯示灰色背景的效果。

<!-- 基礎列表 -->
<ul class="list-group">
    <li class="list-group-item">First item</li>
    <li class="list-group-item">Second item</li>
    <li class="list-group-item">Third item</li>
</ul>

<!-- 連結互動列表 -->
<div class="list-group mt-3">
    <a href="#" class="list-group-item list-group-item-action">First item</a>
    <a href="#" class="list-group-item list-group-item-action">Second item</a>
    <a href="#" class="list-group-item list-group-item-action">Third item</a>
</div>

⚫ 列表色彩

為 .list-group-item 加上帶有指定意義的情境色彩類別來改變背景顏色。

<ul class="list-group">
    <li class="list-group-item list-group-item-success">成功列表項</li>
    <li class="list-group-item list-group-item-secondary">次要列表項</li>
    <li class="list-group-item list-group-item-info">信息清單項</li>
    <li class="list-group-item list-group-item-warning">警告列表項</li>
    <li class="list-group-item list-group-item-danger">危險列表項</li>
    <li class="list-group-item list-group-item-primary">主要列表項</li>
    <li class="list-group-item list-group-item-dark">深灰色列表項</li>
    <li class="list-group-item list-group-item-light">淺色列表項</li>

導航元件 (Navigation Components)

1. 基礎導航 (Navs) 與對齊方式

💡 BS5 語法更新提醒： 靠右對齊的 .ml-auto 已經被廢除，請改用 .ms-auto (margin-start auto)。

⚫ 水平與垂直導航

在 <ul> 添加 .nav，選項添加 .nav-item，連結添加 .nav-link。加入 .flex-column 可轉為垂直導航。

<!-- 基礎水平導航 -->
<ul class="nav">
    <li class="nav-item"><a class="nav-link" href="#">Link</a></li>
    <li class="nav-item"><a class="nav-link disabled" href="#">Disabled</a></li>
</ul>

<!-- 垂直導航 -->
<ul class="nav flex-column">...</ul>

⚫ 導航對齊方式

  • .justify-content-center：置中顯示
  • .justify-content-end：靠右對齊
  • .ms-auto：(BS5 語法) 自動推擠靠右
<!-- 導航置中 -->
<ul class="nav justify-content-center">...</ul>
<!-- 導航靠右 -->
<ul class="nav justify-content-end">...</ul>
<!-- 導航自動對齊 (BS5) -->
<ul class="nav ms-auto">...</ul>

2. 選項卡導航 (Tabs & Pills) 與動態切換

⚫ 選項卡與等寬顯示

使用 .nav-tabs (標籤頁) 或 .nav-pills (膠囊)。加入 .nav-justified 可設置齊行等寬顯示。

<!-- 選項卡導航 -->
<ul class="nav nav-tabs">...</ul>

<!-- 等寬膠囊導航 -->
<ul class="nav nav-pills nav-justified">...</ul>

⚫ 動態選項卡切換

連結添加 data-bs-toggle="tab"，對應內容區塊添加 .tab-pane。加入 .fade 可實現淡入效果。

<!-- 切換連結 -->
<a class="nav-link active" data-bs-toggle="tab" href="#home">Home</a>

<!-- 對應的內容區塊 -->
<div class="tab-content">
    <div class="tab-pane fade show active container" id="home">...</div>
    <div class="tab-pane fade container" id="menu1">...</div>
</div>

3. 導覽列基礎與外觀 (Navbar)

⚫ 標準與垂直導覽列

.navbar 為基礎，搭配 .navbar-expand-{sm|md|lg|xl|xxl} 決定在哪個斷點展開為水平。若不加 expand 類別則永遠為垂直堆疊。

<!-- 在 sm 斷點以上水平展開的導覽列 -->
<nav class="navbar navbar-expand-sm bg-light">
    <ul class="navbar-nav">
        <li class="nav-item"><a class="nav-link" href="#">Link 1</a></li>
    </ul>
</nav>

⚫ 色彩與 Logo (Brand)

使用 .bg-* 設定背景，搭配 .navbar-dark (白字) 或 .navbar-light (黑字)。使用 .navbar-brand 放置文字或圖片 Logo。

<!-- 黑底白字導覽列，帶有 Logo 圖片與文字 -->
<nav class="navbar navbar-expand-sm bg-dark navbar-dark">
    <a class="navbar-brand" href="#">
        <img src="logo.jpg" alt="Logo" style="width:40px;"> 品牌名稱
    </a>
</nav>

4. 響應式折疊導覽列 (Navbar Collapse)

在小螢幕上折疊選單，透過點擊漢堡按鈕顯示內容。需設置 .navbar-toggler 按鈕並綁定 data-bs-target。

<nav class="navbar navbar-expand-md bg-dark navbar-dark">
    <!-- Logo -->
    <a class="navbar-brand" href="#">Navbar</a>
    
    <!-- 折疊觸發按鈕 (漢堡選單) -->
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#collapsibleNavbar">
        <span class="navbar-toggler-icon"></span>
    </button>
    
    <!-- 折疊的導航內容區塊 -->
    <div class="collapse navbar-collapse" id="collapsibleNavbar">
        <ul class="navbar-nav">
            <li class="nav-item"><a class="nav-link" href="#">Link 1</a></li>
            <li class="nav-item"><a class="nav-link" href="#">Link 2</a></li>
        </ul>
    </div>
</nav>

5. 導覽列進階：表單、文本與固定定位

💡 BS5 語法更新提醒： 導覽列表單的 .form-inline 類別已被移除，請改用公用類別 .d-flex 來實現同行排版。

⚫ 導覽列內的表單與純文本

使用 .d-flex 排版表單。若要放置非連結文本，使用 .navbar-text 以保持垂直對齊與內距。

<!-- 導覽列表單 (BS5 使用 d-flex) -->
<form class="d-flex">
    <input type="text" class="form-control me-2" placeholder="Search">
    <button class="btn btn-success" type="button">Search</button>
</form>

<!-- 導覽列純文本 -->
<span class="navbar-text">Navbar text</span>

⚫ 固定導覽列定位

使用 .fixed-top 可固定在畫面頂部，.fixed-bottom 則固定在底部。

<!-- 固定在頂部的導覽列 -->
<nav class="navbar navbar-expand-sm bg-dark navbar-dark fixed-top">
    ...
</nav>

<!-- 固定在底部的導覽列 -->
<nav class="navbar navbar-expand-sm bg-dark navbar-dark fixed-bottom">
    ...
</nav>

6. 導航下拉選單與麵包屑導航

💡 BS5 語法更新提醒： 麵包屑導航官方建議使用 <ol> 與 <li> 標籤結構以符合無障礙規範。下拉觸發需加上 data-bs-toggle。

⚫ 導航帶下拉選單

<ul class="nav nav-pills">
    <li class="nav-item dropdown">
        <a class="nav-link dropdown-toggle" data-bs-toggle="dropdown" href="#">
            Dropdown
        </a>
        <div class="dropdown-menu">
            <a class="dropdown-item" href="#">Link 1</a>
            <a class="dropdown-item" href="#">Link 2</a>
        </div>
    </li>
</ul>

⚫ 麵包屑導航 (Breadcrumb)

顯示當前頁面在導航層次結構內的位置。

<!-- BS5 官方標準結構 -->
<nav aria-label="breadcrumb">
    <ol class="breadcrumb">
        <li class="breadcrumb-item"><a href="#">Home</a></li>
        <li class="breadcrumb-item"><a href="#">Library</a></li>
        <li class="breadcrumb-item active" aria-current="page">Data</li>
    </ol>
</nav>

動態互動元件 (Interactive Components)

模態框 (Modal)

覆蓋在父頁面上的彈出視窗。需使用 data-bs-toggle="modal" 觸發。

<!-- 觸發按鈕 -->
<button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">
    打開模態框
</button>

<!-- 模態框結構 -->
<div class="modal fade" id="myModal">
    <div class="modal-dialog">
        <div class="modal-content">
            <!-- 頭部 -->
            <div class="modal-header">
                <h4 class="modal-title">標題</h4>
                <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
            </div>
            <!-- 內容 -->
            <div class="modal-body">模態框內容..</div>
            <!-- 底部 -->
            <div class="modal-footer">
                <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">關閉</button>
            </div>
        </div>
    </div>
</div>

折疊面板 (Collapse & Accordion)

💡 BS5 語法更新提醒： 觸發屬性皆需加上 -bs- 前綴 (如 data-bs-toggle)。此外，BS5 的手風琴已不再依賴卡片 (Card) 結構，改為使用專屬的 .accordion 相關類別。

⚫ 簡單折疊面板 (Collapse)

.collapse 類用於指定一個折疊元素，點擊按鈕後會在隱藏與顯示之間切換，需要在 <a> 或 <button> 元素上添加 data-bs-toggle="collapse" 屬性。可使用 data-bs-target="#id" 或 href="#id" 來指定目標。

<!-- 簡單的折疊 -->
<a href="#demo" class="btn btn-primary" data-bs-toggle="collapse">
    簡單的折疊
</a>

<div id="demo" class="collapse mt-2">
    <div class="card card-body">
        Lorem ipsum dolor sit amet, consectetur adipisicing elit...
    </div>
</div>

⚫ 手風琴折疊面板 (Accordion)

利用 data-bs-parent 屬性來確保所有的折疊元素在指定的父元素下，這樣就能實現在展開一個面板時，其他的面板會自動收合隱藏。

<!-- 手風琴結構 (BS5 語法) -->
<div class="accordion" id="myAccordion">
    <div class="accordion-item">
        <h2 class="accordion-header">
            <button class="accordion-button" data-bs-toggle="collapse" data-bs-target="#panel1">
                選項一
            </button>
        </h2>
        <!-- 加上 data-bs-parent 實現手風琴效果 -->
        <div id="panel1" class="accordion-collapse collapse show" data-bs-parent="#myAccordion">
            <div class="accordion-body">內容 1</div>
        </div>
    </div>
</div>

圖片輪播 (Carousel)

使用 data-bs-ride="carousel" 自動播放。包含指示點 (Indicators)、圖片內容與左右切換控制。

<div id="demo" class="carousel slide" data-bs-ride="carousel">
    <!-- 指示符 -->
    <div class="carousel-indicators">
        <button type="button" data-bs-target="#demo" data-bs-slide-to="0" class="active"></button>
        <button type="button" data-bs-target="#demo" data-bs-slide-to="1"></button>
        <button type="button" data-bs-target="#demo" data-bs-slide-to="2"></button>
    </div>
    <!-- 輪播圖片 -->
    <div class="carousel-inner">
        <div class="carousel-item active"><img src="img1.jpg" class="d-block w-100"></div>
        <div class="carousel-item"><img src="img2.jpg" class="d-block w-100"></div>
    </div>
    <!-- 左右切換按鈕 -->
    <button class="carousel-control-prev" type="button" data-bs-target="#demo" data-bs-slide="prev">
        <span class="carousel-control-prev-icon"></span>
    </button>
    <button class="carousel-control-next" type="button" data-bs-target="#demo" data-bs-slide="next">
        <span class="carousel-control-next-icon"></span>
    </button>
</div>

提示框 (Tooltip) & 滾動監聽 (Scrollspy)

Tooltip 在 BS5 需透過 JS 初始化；Scrollspy 會根據捲軸位置自動更新導航目標的 .active 狀態。

<!-- 提示框 (Tooltip) -->
<a href="#" data-bs-toggle="tooltip" title="我是提示內容!">滑鼠移動到我這</a>
<script>
    // BS5 現代 Vanilla JS 啟動方式
    var tooltipTriggerList = [].slice.call(document.querySelectorAll('[data-bs-toggle="tooltip"]'))
    var tooltipList = tooltipTriggerList.map(function (tooltipTriggerEl) {
        return new bootstrap.Tooltip(tooltipTriggerEl)
    })
</script>

<!-- 滾動監聽 (Scrollspy) 寫在 body 標籤上 -->
<body data-bs-spy="scroll" data-bs-target=".navbar" data-bs-offset="50">...</body>

外觀與佈局 (Appearance & Layout Utilities)

邊框與邊框色彩 (Borders)

💡 BS5 語法更新提醒： 移除左右邊框的類別已從 border-left-0 / right-0 改為 border-start-0 / end-0。

⚫ 邊框顯示與移除

使用 .border 類別可以添加或移除特定方向的邊框：

<span class="border"></span>
<span class="border border-0"></span>
<span class="border border-top-0"></span>
<span class="border border-end-0"></span> <!-- BS5 語法: 移除右邊框 -->
<span class="border border-bottom-0"></span>
<span class="border border-start-0"></span> <!-- BS5 語法: 移除左邊框 -->

⚫ 邊框色彩

搭配情境色彩類別來改變邊框顏色：

<span class="border border-primary"></span>
<span class="border border-secondary"></span>
<span class="border border-success"></span>
<span class="border border-danger"></span>
<span class="border border-warning"></span>
<span class="border border-info"></span>
<span class="border border-light"></span>
<span class="border border-dark"></span>
<span class="border border-white"></span>

佈局：浮動、置中與寬高 (Layout & Sizing)

💡 BS5 語法更新提醒： 左右浮動的類別已從 float-left / right 徹底改為 float-start / end。

⚫ 浮動與居中對齊

.clearfix 用於清除浮動；.mx-auto 設置水平居中對齊 (元素本身需有寬度)。

<!-- 浮動與清除浮動 -->
<div class="clearfix">
    <span class="float-start">左浮動</span>
    <span class="float-end">右浮動</span>
</div>

<!-- 居中對齊 -->
<div class="mx-auto bg-warning" style="width:150px">
    置中顯示
</div>

⚫ 寬度與高度

使用 w-* 與 h-* 類別 (數值為 25, 50, 75, 100) 或最大寬高 mw-100、mh-100。

<!-- 寬度 -->
<div class="w-25 bg-warning">寬度 25%</div>
<div class="w-50 bg-warning">寬度 50%</div>
<div class="w-75 bg-warning">寬度 75%</div>
<div class="w-100 bg-warning">寬度 100%</div>
<div class="mw-100 bg-warning">最大寬度 100%</div>

<!-- 高度 (父元素需有高度基準) -->
<div style="height:200px;background-color:#ddd">
    <div class="h-25 bg-warning">高度 25%</div>
    <div class="h-50 bg-warning">高度 50%</div>
    <div class="h-75 bg-warning">高度 75%</div>
    <div class="h-100 bg-warning">高度 100%</div>
    <div class="mh-100 bg-warning" style="height:500px">最大高度 100%</div>
</div>
